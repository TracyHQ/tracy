  **Affects:** The `write` step of a run built from a draft, the order check of the `order` step, and whoever builds the real door client. The order check (`markup_forbidden`, redoable) now also refuses an attribute an emphasis part does not declare and a tag in the other form than the field's `inline.write`. New typed stops, none re-run: `markup_runs_code` (any value written as HTML, or any address, that runs code) and `slot_missing`. `held_text_in_value` reads every character reference, accents and zero width characters. `plan.conflicts` rows gain `written` and are one per entry and place; conflicts are no longer in `plan.skipped`; menu items in other words are conflicts. A run's `counts` are `{ops, written, skipped, conflicted, conflicts}` and the step's `recorded` summary carries the conflicts' entry ids. New skip reason `menu_item_without_label`; an in-place value with no slot is skipped at plan time (`kept_record_without_slot`). The read back compares the untouched parts of every edited HTML value (`what: 'untouched value'`); a read back difference is redone once, then stops. A `write_record_stale` report names what the stale record had done. The memory site refuses an apply id reused at another door or with another payload (`APPLY_ID_REUSED`), reads every entity and writes untouched nodes back as read.
