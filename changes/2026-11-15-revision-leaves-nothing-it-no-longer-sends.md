  **Affects:** Whoever reads a revision's run record or wires its build store. A JSON key the previous build owned that a revision no longer sends is taken out, and a column a made record's whole write no longer sends is emptied (`''`; `state.cleared` lists it), every owner key kept; taking either off over an owner's edit stops `site_changed_outside`, and a column with no empty value stops `revision_needs_removal`. `undo.prior` keeps the shape the previous build owned, so a restore and an abandon put those keys and columns back. A blank holder the site fills at a key a revision newly owns is no longer taken for an owner's edit. `restoreBuild` stops `previous_run_unfinished` before any door while `builds.unfinished` answers a run. A revision calls `builds.begin` only after every check that writes nothing, and a run that stops with no door write (`state.touched` unset) has its mark cleared (`builds.end`). A media delete needs a dry run answer of the measured shape (`{usedIn: [{kind, id}]}`); any other answer keeps the file (`used_in_unread`). Each removal act is checked again on every column right before it runs. Docs: `docs/references/draft-revision-run.md`.
