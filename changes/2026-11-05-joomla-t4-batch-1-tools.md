- **Quickstart capture, content coverage and template kit read five more Joomla T4 templates right (Kinetic, Impact, Symphony, Nova, Vega)** — Akemi (Claude) · #pending · `feat/joomla-t4-batch-1-tools` · 2026-11-05
  **Affects:** contracts and kits built from now on. Capture no longer declares twice a `menuitem_config` field the JSON walk already declared; declares custom field values of users and articles, the author's `profile.address1`, and the T4 template config the visitor sees (mega menu column titles and section backgrounds from `etc/{layout,navigation}/*.json` and the style's `mega_settings`) as a new `templateConfig` kind — the Claude Cowork plugin writes it from 0.24.80. Content coverage: a text field holding a web address is the slot of the link that prints it; a page heading keeps its h1 mark when a breadcrumb prints the same words first; a tag page is tied to its tag when its heading prints the tag's words, whichever slot the matcher gave them; a module alone in its position is found by the position wrapper; a menu entry of type `url` declares the address it opens as a `link` slot after its title, and the slot role rule tables make a social one (by its address or its title naming the network) a contact card, the nth social entry of a menu showing the business's nth profile; label rules let a money amount pass on `stat.value` / `claim.notice` and skip code inside `<pre>`/`<code>`. Template kit: a further result page with only some of page 1's parts is page 1's pagination; an account's author page stays when a later page of it ships content; a menu no captured page draws does not ask its dead `#` items to be link labels; on a tie a block reads its own menu module; a block with no entity of its own names a slot of the module its other slots come from; a module printed inside a block with no wrapper of its own (in a T4 layout column named after its position, or at a position another module's params name) is that block's content, its icon-only links taking its rows' address slots in order; an unpublished module is no block of the page. A `url` menu entry's link is that entry's address slot, listed on the block. A picture in a container whose class holds "logo" is a site logo only in the header, the footer or the off-canvas menu (in the page body it is a client strip or a feature icon); a logo inside a block that holds no slot with its file is the site-level logo slot's (the template's footer or off-canvas logo element inside a module's section); a logo with no slot is written by the template logo setting whose layout prints there, holding its file or empty (the layout then prints its stand-in); a colour a stylesheet variable names primary, brand or accent stays the brand colour when a status rule reuses it (an alert border, an error page class). The label judge's locator no longer takes an address slot whose demo value is `#` as evidence of where its entity sits. Contracts and kits built before this read differently on rebuild; a template with url menu entries (Impact, Phio, Spa, Vega…) gets new slots its label review must answer.
  **Why / Measured:** each fix came from a kit self-check or a coverage hole the template itself did not cause, on the five templates of Joomla T4 batch 1; every one has a test (quickstart-tools 448/448, joomla-quickstart 88/88, slot-role rule tables 4/4, tracy-web kit and API reference 141/141).
