- **A campaign link pressed by someone already signed in is now counted (`link.visited`)** — Claude, for Sarah · #315 · `feat/signed-in-utm-visit` · 2026-11-03
  **Affects:** tracy-web (`workspace/route.js`, `lib/ops-signal.js`). A signed-in `GET /` with `utm_*` that wants HTML records `link.visited {source, medium, campaign, content}` with the account, one per person and source each half hour (`linkVisitKey`), never during a view-as. The redirect itself is unchanged. Anyone reading visits per `utm_content` adds `link.visited` (signed in) to `login.visited` (signed out); the visit-to-sign-in rate still reads `login.visited` only. Counts start once the `tracy-web` image with this change is deployed.
  **Why / Measured:** 87 lifecycle mails sent on 2026-11-02 to existing customers left no click record at all, because a signed-in browser never reaches `/login`; the only trace was who later entered a site or replied.
