  **Affects:** anything reading a template kit. A link whose words are not the customer's carries `fixedLabel: {rule, reason}` (`template-words`, `icon-name`, `pagination`). A phone-number link now names its block's phone slot. New command `cli.mjs relabel --out <dir> --contract <dir>` settles the labels of a written kit without a capture. The JA Boxing 1.0.10 kit is rebuilt this way: 257 links name a label slot, 135 carry a reason, `linksWithoutLabel` 0, image set and approval unchanged; the release zip `template-kit-ja-boxing-1.0.10.zip` is replaced.
