- **Template kit 3.1.5: a `?page=`, `?paged=` or `/page/N/` result page is a pagination link, not a link-label error; a rebuild keeps each page's `fullShotOf`** — kit tool maintainers · #9999 · `fix/template-kit-page-pagination` · 2026-11-25
  **Affects:** whoever builds or settles a template kit. The link-label rule (`link-label-reasons.mjs`) knew only Joomla's `?start=`, so EmDash pagers (JA Impact Donations and Events) and WordPress pagers failed the kit; `page`, `paged` and `/page/N/` now count like `start`. `assemble` and a build without `--full` wrote the kit again without a pack step and dropped `fullShotOf` from a kit that held it (JA Morgan); `keepFullShots` (`pack.mjs`) carries it over by page id, and `pack` still makes it again from the current groups. Tool version 3.1.5 (`lib/version.mjs`).
