- **Template kit 3.1.5: a `?page=` or `?paged=` result page is a pagination link, not a link-label error; a rebuild keeps each page's `fullShotOf`; a Prev/Next link finds the title of the page it opens when the page is read as sections** — kit tool maintainers · #9999 · `fix/template-kit-page-pagination` · 2026-11-25
  **Affects:** whoever builds or settles a template kit. The link-label rule (`link-label-reasons.mjs`) knew only Joomla's `?start=`, so EmDash pagers (JA Impact Donations and Events) and WordPress `?paged=` pagers failed the kit; `page` and `paged` now count like `start`. `assemble` and a build without `--full` wrote the kit again without a pack step and dropped `fullShotOf` from a kit that held it (JA Morgan); `keepFullShots` (`pack.mjs`) carries it over by page id, and `pack` still makes it again from the current groups. Tool version 3.1.5 (`lib/version.mjs`). `relabel` and `assemble` left 28 Prev/Next links of JA Nova without a label when `emdash-sections.json` was present: the sections map moves a page's slots under its section blocks' entities, and the label rule looked for the opened page's own entity (`link-label-slots.mjs`, `ofEntity`); a slot now also belongs to the entity its key starts with. A result page number must be a whole number (`start` 0 up, `page` and `paged` 1 up). A `/page/N/` path is not read as pagination: nothing tells it from a real page at that path. `keepFullShots` keeps a value only when the page it points to is still in the kit and in the page's group.
