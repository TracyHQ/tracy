- **`cut_mark` and `recolour_mark` join the brand step tools, `make_favicon` tries its recoloured-mark candidate for real, and a run can switch its reviewer with an explicit one-off override** — Claude, for Akemi · #321 · `feat/brand-bench-tools` · 2026-11-03
  **Affects:** nobody yet; the brand bench (#314) will call them. `brandTools` now lists `cut_mark(mediaId, box)` and `recolour_mark(mark, side)` with the same names, inputs and outputs as the approved lab tools; paths are run folder relative and a tool never overwrites (`mark/cut-mark.png`, `mark/cut-mark.mask.png`, `mark/recoloured.<side>.png`, a taken name gets `.vN`). The bench CLI gets `--reviewer-model <model>`, valid only with `--agent-model` and `--agent-model-reason`.
  **Why / Measured:** `cut_mark` removes only the ground connected to the crop border, so ground the figure encloses keeps its original opaque pixels, and it writes the mask sidecar that `recolour_mark` reads. `recolour_mark` inverts a cut mark by OKLab lightness (kept fill takes the side ground, figure tones run to the side heading colour with a 3:1 floor), recolours an icon by palette (colours under 3:1 take the heading colour) and turns a lettermark into one solid colour. Parity was run locally against the lab scripts on code-drawn logos (a ring on a plain ground, a shield on a gradient ground, a transparent mark, a two-colour icon, both sides, auto and solid modes): every output, mask included, is identical pixel for pixel. `make_favicon` no longer skips its third candidate: when the transparent and tile icons fail it calls `recolour_mark` on the opening side's mark (`ctx.recolourMark` stays as a test seam). Fallback: `--agent-model` takes any non-Anthropic agent model for one run; `--reviewer-model` switches the reviewer the same way, so the agent and the reviewer never match. Nothing switches on its own: the same model on both doors is still refused, and both overrides are stored in the run with the reason and the model each replaced. The end-to-end test now has the gate accept a brand file for a found logo with a symbol (cut, recolour for the dark side, compose, fit, favicon, looks).
