- **Every page the author writes is checked against the site plan, a plan with no page is refused, and a dropped page is not written.** — build maintainers · #236 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** Joomla brief builds with an accepted site plan. After the shared checks, each page is judged on the plan axis (`planConformance` in `page-author.mjs`): it writes nothing into a section the plan hid, it names a glossary item as the glossary spells it (and uses the glossary description where the slot is that item's description and the description fits), and it carries the lead and every fact the plan assigned. A card is tied to its glossary item by the names the plan gave the cards of its collection. A failing page goes back to the same author with the reasons inside the existing bounded send-back; a line still failing is refused and traced in `copyLineTrace` with the check `plan-conformance`, and a missing lead or fact is traced under the page's first line. The plan check refuses a plan that keeps no page (rule `no-page-kept`). A slot shown only on dropped pages gets no writer call (`pageAuthor.dropped` on the build record). Facts with a figure are matched by the business-fact detector, other facts and the lead by their main words. People are not bound to the glossary yet, only offerings and plan card items. WordPress and EmDash are not done. Rebuild the web image before the next brief build.
