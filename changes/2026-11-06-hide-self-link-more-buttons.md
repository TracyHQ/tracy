- **The write step hides a template's "more" buttons that lead to the page they sit on, page by page, in the containers the kit names (card AF)** — Write step · #TBD · `fix/hide-empty-video-play-buttons` · 2026-11-06
  **Affects:** template kits gain `site.selfLinkButtons` (`template-kit/cli.mjs self-link-buttons --kit <file> --container '<css>' --why '<where>'`, or `--none`); the JA Boxing 1.0.11 kit names `.bottom-actions`. After the route stage the write step writes, between `tracy-self-links` markers in the kit's head injection block, one rule per kept page scoped by T4's body classes and naming only that page's own addresses (`write-step/self-link-buttons-stage.js`); the look guard allows only such rules (`self-link-buttons` exception). tracy-host's `selfLinks` measure now carries `holders`, and the `self-links` site check group blames step 9 for a shown self link inside a declared container. A host image built before this change answers no holders, so such a button keeps its old owner until the image is rebuilt. ADR 0044 decision 27 covers this second use.
  **Why / Measured:** card AF: on a bench site with the JA Boxing 1.0.11 kit the Coaches page showed VIEW MORE (module-178, `link-btn` = `index.php?Itemid=195`) opening the Coaches page itself; the contract has no slot for module params (issue #369). In a headless Chromium on an invented page the rule hides the self link and keeps a link to another page in the same container (`apps/tracy-host/test/demo-qa-reach-measures-browser.test.mjs`).
