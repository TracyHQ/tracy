- **Brief build item icons: one glyph per item in a section, chosen by the text model, from a larger icon set** — Akemi (Claude) · #189 · `feat/brief-build-own-site` · 2026-10-29
  **Affects:** every Joomla brief build whose template has item icons (role `editorial.item_icon` or `decor: "subject"`); the decor plan version is now `decor-plan/3`; the Joomla engine's picture step asks the writer's text model one extra short question per build when the template has item icons.
  - No two items of one section (the entity the icons sit in) show the same glyph. Each item ranks candidate glyphs (the text model's reading of its words first, then the keyword lexicon on its words, the offering of its page, the brief's offering of its place); items are assigned in page order, each taking its best unused candidate, else an unused neutral mark (`check`, `spark`, `circle-dot`, `diamond`, `hexagon`). A dark and a light icon of one item keep one glyph. `domain/icon-choice.mjs`.
  - The model returns glyph names from the set only; unknown names are dropped. No model, a failure, a timeout (30 s) or no usable name: the keyword lexicon decides, with a build note. Answers are kept in memory by question (`sites/brief-engines/icon-meanings.js`).
  - The icon set (`lib/icon-glyphs.js`) grows from 25 to 66 glyphs in the same line style (24 x 24, round strokes): racquet sports apart (tennis, padel, squash, badminton, pickleball), fitness, bakery, dental, beauty, spa, food and common trades, plus the neutral marks.
  **Why / Measured:** on a local brief build the "Tennis coaching" and "Padel coaching" cards of one section showed the same racquet, and the four feature icons of each offering page all showed that page's one glyph.
