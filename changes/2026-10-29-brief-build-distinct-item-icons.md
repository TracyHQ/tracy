- **Brief build item icons: one glyph per item in a section, chosen by the text model, drawn from Phosphor Icons in the template's own style** — Akemi (Claude) · #189 · `feat/brief-build-own-site` · 2026-10-29
  **Affects:** every Joomla brief build whose template has item icons (role `editorial.item_icon` or `decor: "subject"`); the decor plan version is now `decor-plan/3`; the Joomla engine's picture step asks the writer's text model one extra short question per build when the template has item icons.
  - No two items of one section (the entity the icons sit in) show the same glyph. Each item ranks candidate glyphs (the text model's reading of its words first, then the keyword lexicon on its words, the offering of its page, the brief's offering of its place); items are assigned in page order, each taking its best unused candidate, else an unused neutral mark (`check-circle`, `star`, `sparkle`, `circle`, `diamond`, `hexagon`). A dark and a light icon of one item keep one glyph. `domain/icon-choice.mjs`.
  - Each item gets a menu of at most 60 icon names, shortlisted from the icon set's own catalog (names, tags) plus the keyword lexicon and the offering; the model ranks names from that menu only, and unknown names are dropped. No model, a failure, a timeout (30 s) or no usable name: the keyword lexicon decides, with a build note. Answers are kept in memory by question (`sites/brief-engines/icon-meanings.js`).
  - Icons now come from Phosphor Icons (`@phosphor-icons/core` 2.1.1, MIT, 1512 icons in six weights), a dependency of `@tracy/web` read from the installed package (`lib/phosphor-icons.js`); Tracy's own hand-drawn glyph table is removed. Rendering is unchanged: a transparent PNG of the demo icon's size, in the colour `iconColourOf` reads. Reason: Phosphor covers any trade and any template style, where a hand-drawn set covers the trades someone drew (COO 2026-10-29).
  - Style match: the demo icon being replaced is measured (`lib/icon-style.js`): outline stroke against its box picks `thin`, `light`, `regular` or `bold`; solid ink picks `fill`; a tinted fill or a second ink colour picks `duotone`; a disc or tile behind the glyph is read as its ground, and the new glyph is drawn on a ground of the same shape (corner radius read from how much of its box it fills), colour, opacity and size, in the demo glyph's place, per demo file so a dark and a light demo each keep their own (COO 2026-10-29: replace the content, never the template's style). Every icon of a section takes the section's most common weight. The receipt and the unit id carry the weight.
  **Why / Measured:** on a local brief build the "Tennis coaching" and "Padel coaching" cards of one section showed the same racquet, and the four feature icons of each offering page all showed that page's one glyph.
