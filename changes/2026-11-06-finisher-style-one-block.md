- **The finisher can repair unreadable text and broken layout with "style one block": one allow list CSS rule per block in its own marked block of the head injection module** · Akemi (with Claude Code) · #426 · `feat/finisher-421` · 2026-11-06
  **Affects:** whoever runs `write-step-bench.mjs finish`, reads a site's head injection module, or changes the look guard. Two fault kinds join the finisher's list (`unreadable-text`, `broken-layout`) and one repair order (`style-block`: a block, an optional target inside it, and declarations). Code accepts only text colour, a backing layer (colour or gradient), text shadow, font size, line height, spacing (no negative margins) and long word wrapping, and refuses by name anything that hides content (display, visibility, opacity, height, max-height, position, transform, offsets, indent, transparent or tiny text, pictures); one refused declaration drops the whole order and nothing is written. The rule goes between `<!-- tracy-finisher-style:start -->` markers in the kit's head injection module through `content.update`, one line per block naming it, scoped to `#Mod<N>` or the block's ACM id; the undo puts back only that block's rule. The look guard lets that block hold only such rules (`finisher-style`). ADR 0044 gains decision 30 (a model may decide repairs in step 9 within closed orders; the second bounded CSS exception), and CONTEXT.md gains Finisher, Repair order, Repair log and Finisher style block.
