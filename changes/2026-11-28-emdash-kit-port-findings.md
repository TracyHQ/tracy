- **EmDash kit tool: the defects four JA template ports hit** — kit tool (Vega, Impact, Morgan, Nova ports) · #777 · `fix/emdash-kit-port-findings` · 2026-11-28
  **Affects:** anyone cutting an EmDash kit (`template-kit`, `content-coverage/emdash-content-map.mjs`) and the EmDash themes' `src/lib/stamps.ts`. Joomla and WordPress kits read as before: `?page=N` is kept only under the EmDash plain url style, and the slider whole-multiple row match runs only for EmDash maps.
  - `stamps.ts` (kit source and the eight theme copies, identical): a stamp key may hold `[` and `]`, so `items[0].title` prints a stamp. Diner (`Home.astro`), Restaurant (`Stats`, `Slideshow`) and Fresco (`MenuCards`) print such keys today and had printed none; their kits see repeater fields after the next cut.
  - On EmDash, `?page=N` is a position key, so the pager's "2" link keeps its page. `link-label-slots` also picks a slot the stamps place in the link's own block (`alsoIn`, set by `emdash-map.mjs` for every block a stamp appears in; `kit-blocks.mjs` no longer calls it foreign), and a taxonomy term's page opens that term.
  - A link to, and a page titled by, a taxonomy term's page (`itemPages` or a listed page named by the term slot key) is a `taxonomy-term` link / title (`titleVia`), at any path. Two hero slides printing one h1 take the first row's slot.
  - Content map: `link_title` / `link_label` are text, `btn_link_2` is an address, and a sub-field's declared `source` (`<collection>.<field>.<sub>`) wins. No committed map changes type; a regenerated Base map gets text `link_label` slots, and Fresco's `btn_link_2` now matches its committed url slot. `emdash-content-map.mjs --write` keeps `fit`, `customize`, `slotFitVersion` and `fitGroups` for unchanged slots.
  - Row reader: a slider's `aria-hidden` copies are not rows, and a numbered modifier (`vg-chip-1` beside `vg-chip`) does not split the row shape.
  **Why:** the four ports listed these as tool defects; each has a case in `test/template-kit-port-defects.test.mjs`.
