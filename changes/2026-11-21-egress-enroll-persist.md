- **Site networks stay behind the egress fence after a host reboot** — Lucas (with Claude) · #718 · `egress-enroll-persist` · 2026-11-21
  **Affects:** fleet hosts. `bootstrap.sh` installs `/usr/local/sbin/tracy-egress-enroll.sh` and enables `tracy-egress-enroll.timer` (boot + every 5 min), which enrols every `10.240.x` site network in `TRACY-FLEET-EGRESS` and runs `netfilter-persistent save` when it added one. Existing hosts: rerun `bootstrap.sh` (idempotent) or install the three files by hand. `provision.sh` no longer hides a failed save.
  **Why / Measured:** provision runs in tracy-host, where `netfilter-persistent` does not exist, so new site networks were never persisted. After the 21/11/2026 kernel reboot, 12 production and 20 dev site networks were unfenced. Case REG-PR-718-egress-enroll-persist.
