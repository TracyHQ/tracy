- **The cleanup after a brief build is a bounded repair loop, and the site's agent checks a changed page against the site build rules.** — build maintainers · #189 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** brief builds and the site agent on every CMS. The one cleanup turn becomes at most three rounds in the same chat: each round's prompt lists only the findings a site build rule can repair, blockers first, with the rule's repair text and guarantee and the hard-facts rule; the full check (contact facts and the first screen included) runs after each round, and the loop stops when nothing is left, the count did not fall, a page was lost, the turn errored or timed out, the third round ended, or the 20 minutes ran out. The receipt's `leftoverCleanup` keeps its fields and adds `rounds[]` and `stopped`; a round that was running when its worker died is marked interrupted and only re-checked. The site agent gets the generated `site-build-rules` skill (Developer and Writer presets of all three CMS), a `BUILD RULES` line in the site context, and the `tracy_build_check` tool, which asks the new internal door `GET /api/sites/:key/build-check?path=` for that page's findings. Rebuild the web and dsh images.
