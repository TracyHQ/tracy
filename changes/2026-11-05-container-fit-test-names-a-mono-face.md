- **Template kit container-fit test names Liberation Mono instead of the generic `monospace`, and says so when no fixed-pitch face is installed** · hano-xbt · #390 · `fix/quickstart-tools-nightly` · 2026-11-05
  **Affects:** whoever reads a red `@tracy/quickstart-tools#test:ci`, and anyone running browser tests on a self-hosted runner. Product code is unchanged.
  **Why / Measured:** the 04/11 nightly ran on a self-hosted runner, where Chromium and its fonts come from `playwright install --with-deps` on Ubuntu 24.04. That installs fonts-liberation and fonts-wqy-zenhei but no DejaVu, so fontconfig resolves `monospace` to WenQuanYi Zen Hei Mono, whose Latin letters are proportional and 8px wide. Three tests in `test/template-kit-container-fit.test.mjs` then read longer limits (tab 30, address 49, menu row 46) than their 9.6px bounds allow. A local fontconfig limited to that font set gives those exact numbers. The test now asks for "Liberation Mono" by name and passes with that font set and with a Debian one. A machine with no fixed-pitch face fails with "no fixed-pitch face of about 9.6px … install fonts-liberation" before any reading.
