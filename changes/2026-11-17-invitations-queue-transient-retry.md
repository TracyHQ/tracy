- **An Invitations send queue also waits out an unexpected error and a Gmail token refusal for 30 minutes before pausing** · Sarah (Claude) · #671 · `fix/invitations-queue-transient-retry` · 2026-11-17
  **Affects:** tracy-web (`invitations/real-queue.js`). `REAL_INTERNAL` (inside a send or anywhere in a cron pass) and a Gmail token refusal (`MAILBOX_TOKEN_UNAVAILABLE`) now get the same `AMEMBER_RETRY_MS` window as aMember outages: the queue waits and tries the same customer again on later passes, and pauses only when the error lasts the whole window. A token refusal no longer skips the customer: the next try sends under a new request key (`queue-<recipient>-r<rev>-a<n>`). No migration; pauses still reach the ops topic. Rebuild and deploy tracy-web for it to take effect.
  **Why / Measured:** 16/11/2026 the Black Friday renewal queue paused at 13:23 on `REAL_INTERNAL` with the mailbox connected and lay still for 20 hours until Resume, which worked at once; 05/11/2026 a queue paused on `MAILBOX_TOKEN_UNAVAILABLE` the same way. Case REG-PR-671-invitations-queue-transient-retry.
