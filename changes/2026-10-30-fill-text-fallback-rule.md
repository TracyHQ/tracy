- **One rule for a short text the fill stage refuses: it falls back to a brief value and the build goes on.** — build maintainers · #189 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** brief builds on every CMS. A footer column heading or link label, a main menu label, a declared button label or an offering summary that fails its check (demo, generic, empty, too long, duplicate, not translated) no longer throws `FOOTER_INVALID`, `BUTTON_ACTION_DOES_NOT_FIT`, `BUTTON_ACTION_TRANSLATION_REQUIRED`, `OFFERING_SUMMARY_REQUIRED` or `OFFERING_SUMMARY_TRANSLATION_REQUIRED`. The shared helper `text-fallback.js` takes the first deterministic value that passes the same check (offerings page name or title, business name, page title, offering name, the name the page address reads); the swap is noted in the build receipt. When nothing passes, the item is a blocker line in the receipt, left as it is (or out of its footer column) for the final check. A missing page, a refused write or a wrong readback still stops the build. The footer writers take an optional `note`; the Joomla engine does not pass it yet.
