- **A WooCommerce order placed on live under a number the copy uses moves with its post.** — David · issue #107 · `fix/sync-wc-order-renumber` · 2026-10-29
  **Affects:** Sync from live on WordPress with WooCommerce. When a live order (HPOS or legacy) lands on a post number the copy already holds, `wc_orders.id`, its refunds' `parent_order_id`, and the `order_id`/`product_id`/`variation_id` of its lines, addresses, meta, downloads and lookups are renumbered together with the placeholder post, so the order never attaches to the copy's post. A live record moved off a remembered number ("occupied") now also holds rows of unknown plugin tables that name it, as a clash already did.
