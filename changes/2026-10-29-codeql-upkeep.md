- **Dependabot keeps the SHA-pinned GitHub Actions current with one weekly grouped pull request into `develop`, and a daily `CodeQL Freshness` run goes red when CodeQL scanning of `develop` or `main` has stopped** — CI maintainer (Claude) · #PR · `ci-codeql-upkeep` · 2026-10-29
  **Affects:** CI maintainers and whoever merges into `develop`. `.github/dependabot.yml` updates `github-actions` only (workflows and `.github/actions/*`), no npm versions; its pull request is titled `ci(actions): bump …`. Auto-merge already takes only pull requests opened by a person of the team (`authorRefusal` in `scripts/auto-merge-develop.mjs`, #130), so a Dependabot pull request is merged by hand. Its body is Dependabot's, so `PR Description Check` stays red until someone fills in the template sections (an edit re-runs it), and `language-policy` reads upstream release notes in the body, which fail it when they hold a non-ASCII letter (trim them). `.github/workflows/codeql-freshness.yml` reads the newest analysis per category (`/language:javascript-typescript`, `/language:python`, `/language:actions`) with the job token. `develop` is stale when a category has no analysis of the develop head commit (`commit_sha`) although that commit was committed more than 24 h ago; a younger head may still be scanning, and a develop with no new commits whose head was analyzed never goes red. A head commit carrying `[skip ci]` starts no CodeQL run, so it stays red until the next push (the message says so); `main` (the default branch, which gets the weekly scan) is stale when a category's newest analysis is more than 8 days old. A missing category or an API error fails closed. A red run names the ref, the category and its last analysis (for develop also that analysis's commit, and the head commit with its date); it means `codeql.yml` stopped analyzing or default setup was switched back on. It runs once it reaches `main` (GitHub starts scheduled workflows from the default branch). Adding a language to `codeql.yml` means adding its category to `scripts/ci/codeql-freshness.mjs` (`scripts/test/codeql-freshness.test.mjs` fails until both match).
