- **Kept links lead where the plan says, lists keep exactly the plan's rows, maps move to the business, phones can be called** · Claude, for Akemi · #370 · `feat/write-step-bench` · 2026-11-05
  **Affects:** the template kit, the write step and the site check bench. Three new kit counters (`deadControls`, `mapLocationUnmapped`, `phoneNotCallable`) keep a kit `kit-incomplete` above 0, and /ops names them on the Template kit step. A write line can now be `refused` (read back as failed on step 9). The write report gains `planLinks`, `endActions`, `phones`, `place` and `rows`. The host answers `lists`, `maps` and `phones` per page, and a demo baseline must be measured again to hold the demo's `maps`. New check groups: `plan-links`, `list-rows`, `map-location`, `phone-callable` (all block). A report or host from before these fields leaves them unmeasured.
  **Why / Measured:** on a bench site a list the plan cut to 2 rows printed 4, two empty, because a kept link wrote a url slot of a later row and so kept that row; a button with no address, a map at the demo's place and a phone printed as text all passed. ADR 0044 decisions 21 to 24.
