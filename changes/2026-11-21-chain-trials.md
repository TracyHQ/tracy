- **Staff can turn a measurement switch of the chain build on and off (`chainTrials`), and the bench-run door shows the first failures of each rule** — David (WO pipeline) · #722 · `perf/wo-chain-trials` · 2026-11-21
  **Affects:** Rebuild and deploy tracy-web. Nothing changes until staff set a switch: `PUT /api/ops/wo/settings` takes `chainTrials` (`{"planTurns": true}` plans round 0 in writing turns of one conversation, ADR 0045 stage 1); the plan step reads it when it starts, adds `--plan-turns` to its planner run and records `trials` on its step. Unknown names or non-boolean values answer 400 `INVALID_CHAIN_TRIALS`. `GET /api/ops/wo/bench-runs/:bench/:runId` rounds gain `errorCode` (why a round made no document, the code only) and `failureSamples`: per rule, the first three failures with where they are and, except for picture rounds, the reason with quoted words, long numbers, e-mail and web addresses masked.
  **Why / Measured:** One setting gave very different builds: BXR London's plan round 0 took 546 s and 761 s on the same prompt (dev lat24b and lat25, 21/11/2026), more than most changes measured with one merged build each. With the switch, two settings run side by side on dev. The 466 R02 failures of one BXR round were only a count. Case REG-PR-722-chain-trials.
