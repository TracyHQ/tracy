- **A plan edit after a build re-runs the writer and the write step only for the pages and blocks it changed, and the build before it can be restored.** -- AI quickstart work for #577 (#599) | PR pending | `feat/ai-quickstart-575` | 2026-11-13
  **Affects:** Whoever starts a draft run from the build chat. Every finished draft run now keeps a build result through `deps.builds.keep(build, ctx)` (optional; without it `value.build.kept` is false and nothing can be revised later), and reports its ref in `value.build.ref`. A run whose brief has `rebuildFrom: <that ref>` is a revision run: it reads the build with `deps.builds.read(ref, ctx)`, calls the writer only for pages whose writer request changed (only their changed blocks), answers pictures and icons from the kept replies, and writes only the operations whose effect changed, on a fresh record. The ref of a build is `<runId>:r<revision>:w<seq>`, and a revision's apply ids start with it (a first build's apply ids are unchanged). `restoreBuild` writes the previous build back from the revision's undo journal; it stops typed for a record the revision made and for a value a new hold covers. `writePages` takes an optional `reuse` map. The caller contract is in `docs/references/draft-revision-run.md`.
