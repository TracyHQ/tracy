- **The write step bench settles the demo baseline once per quickstart version: reused when stored, measured only when none exists** · Akemi (with Claude Code) · #426 · `feat/write-step-finisher` · 2026-11-06
  **Affects:** whoever runs `write-step-bench.mjs` or `site-check-baseline.mjs`. `create-site` makes an untouched site, so it now settles the demo baseline of the kit's version on it: a stored baseline is reused and no page is measured, a missing one is measured once and stored. It prints `baseline reused (stored)`, `baseline measured (none was stored)` or `baseline measured again (forced)`. `create-site --force-baseline` (and `site-check-baseline.mjs --force`) measure again on purpose; do not pass them by default, a measurement costs about six minutes. `check` reads the stored baseline of the run's version and, given a host, prints `baseline reused (stored)` or `baseline: none stored`, in which case the demo groups stay unmeasured. A failed measurement stores nothing and `create-site` exits 1 after the site is made. The production build path (`takeDueBaselines`) reads a different, per build baseline and is unchanged.
