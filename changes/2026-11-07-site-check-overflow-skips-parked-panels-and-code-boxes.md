- **The site check's text-overflow measure no longer counts a closed panel parked off screen, nor a code line inside its own scrolling box** — Joomla T4 batch 1 readiness · `feat/joomla-t4-batch-1-readiness` · 2026-11-07
  **Affects:** the `text-overflow` group of the site check and of `demo-measures` (`apps/tracy-host/src/demo-qa-page-measures.js`), on built sites and on untouched demos. Text inside a `position: fixed` element that lies wholly past the right edge (an off-canvas menu translated out) is no longer "past the right edge"; an element's overflow is now read from its own text, so a child that scrolls in its own box (`pre` with `overflow-x: auto`) no longer makes its parent's paragraph overflow. Text that runs past the edge of a page that scrolls sideways is still reported. Demo measures taken before should be retaken where `text-overflow` was red.
  **Why / Measured:** JA Kinetic j6 1.0.11 at 390 px read `text-overflow` red with 1,337 findings while every page's `scrollWidth` was 390: 1,320 were four texts of the closed off-canvas menu (`transform: translateX(390px)`), 17 the article body around a `pre` code block. The browser test `apps/tracy-host/test/demo-qa-page-measures-browser.test.mjs` fails on the old code (3 findings, expected 1) and passes now: 7 pass, 0 fail.
