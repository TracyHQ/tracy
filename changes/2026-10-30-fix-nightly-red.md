They are harmless: Turbo hashes the union. `website-opportunities-shared-social.test.mjs:211` replaced the secret's last character with `X`. A 24-byte base64url secret ends in `X` 1 time in 64, so the "forged" key was the real one and verified (`undefined` for `SOCIAL_AUTH_INVALID`). This was not timing-dependent: a preload that forces the last character to `X` fails it every time before the fix and passes after it. The same flaw in `preview-ticket.test.mjs` is fixed too. The forgery now changes a character that carries only data bits.
