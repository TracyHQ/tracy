- **A quickstart part fetched from a github.com release download address is fetched again through the GitHub API asset route when that address answers 5xx** — Akemi0x · `fix/quickstart-github-download-504` · 2026-11-08
  **Affects:** every provision and demo update prefetch that reads a part pinned by a plain release URL with no `githubAssetId` (the Claude Cowork plugin zips on TracyHQ/claude-cowork). Nothing to rebuild by hand: the next dsh/host image carries the new `quickstart.py`. A 4xx is still reported as before.
  **Why / Measured:** the JA Voyara 1.0.12 demo update stopped at prefetch three times with `quickstart download failed (HTTP 504)`. The failing part was `pkg_claudecowork-0.24.89.zip`: the github.com release download route answered 504 for every file of release `joomla-v0.24.89` for more than ten minutes, while `api.github.com/repos/TracyHQ/claude-cowork/releases/assets/<id>` served the same bytes (sha256 matching the catalogue) in under a second. With the fix, `quickstart.py --prefetch` on that entry printed the 504, fell back to the API and verified the part in 13 s.
