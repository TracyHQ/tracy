- **The footer lists every kept page; the header main menu may be shorter** — Akemi (Claude) · #189 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** Joomla T3/T4 brief builds and quickstart packing. Content maps declare footer link columns as `navigationGroups` (offerings, company or pages); the packing check refuses a footer menu module that is not declared, and JA Boxing 1.0.8 declares its two. After the main menu, the build lists every kept page and each offering page under an offerings index in the footer columns, with headings the text model writes from what each column holds (demo and generic headings refused), takes an empty column off and reads everything back. The main menu now requires only home, the offerings index, contact or booking and about. The build check reports a footer that misses a kept page, has fewer links than the header, or keeps a demo heading, demo link, dead link or empty label. WordPress and EmDash maps declare no footer groups yet, so their footers are not written or judged. Requires a web image rebuild.
