- **Joomla provisioning reports sanitized metadata when a contract bind returns unreadable or unexpected JSON.** — Pipeline maintainers · #541 · `fix/wo-artifact-integration` · 2026-11-11
  **Affects:** Failed bind and inspect responses retain their HTTP status and refusal behavior while reporting fixed MIME categories, byte counts, JSON error codes and known-field counts. Response bodies, arbitrary MIME values and response keys are not logged. This improves diagnosis of transient provisioning failures; it does not prevent concurrent component updates or accept an unverified bind.
