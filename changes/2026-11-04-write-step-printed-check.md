- **The write step checks that what it wrote is printed, and prints a gated picture itself; the site check blocks on a written value no page prints** — Akemi · `feat/write-step-bench` · 2026-11-04
  **Affects:** the write step and site check bench. Given a page reader (the bench passes one), a run ends with a `printed` phase and the report gains a `printed` section (counts, slots printed via fallback, slots not printed). A kept picture of an article that the template prints only beside a slot the run hid (a video poster without a video id) is written as a `tracy-fallback` block at the top of the article's full text, through `content.update`; the look guard lets a template article's text change by such blocks alone. New site check group `written-not-printed` (step 9), run when a page reader is given.
  **Why / Measured:** on JA Boxing the poster was written to the database and never printed, so its block's height vanished and the text below rose into the header picture, while read-back stayed green and the fault was blamed on the picture step.
