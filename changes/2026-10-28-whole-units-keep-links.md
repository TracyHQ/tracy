- **Joomla capture: `--whole-units` no longer merges a unit whose words sit inside a link** - Akemi (Claude) · #42, #46 · `fix/whole-units-keep-links` · 2026-10-28
  **Affects:** whoever captures a Joomla template contract with `--whole-units`. A heading, paragraph or list item with a word inside an element that carries `href`, `src`, `alt` or `title` (a link, mainly) keeps its text pieces as separate text slots, exactly as without the flag. Units cut only by `<span>`, `<strong>`, `<br>` or an icon `<i>` are still one slot on their element. Attribute slots (`alt`, `title`) are no longer counted when deciding that a fragment has no unit element.
  **Why / Measured:** the Claude Cowork plugin writes an element slot as one text node and keeps every element carrying href/src/alt/title (claude-cowork `ContentSlots::writeUnit`), so a merged `<p>Call <a href="tel:...">us</a> today</p>` was written as `<p>New text<a href="tel:..."></a></p>`, a link with no words. Fixtures: the `C1` cases of `capture-contract.test.mjs`.
