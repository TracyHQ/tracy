- **The template kit reads every link and icon of a block, judges short rows by the content around them, and JA Boxing 1.0.10 ships an approved kit** — Claude, for Akemi · `feat/template-kit` · 2026-11-02
  **Affects:** anyone running `template-kit/cli.mjs build` or reading `template-kit.json`, and the Template kit step of `quickstart/ja-boxing/j6` on the Road to live. The build shoots only the images that go in the pack and re-reads everything else in the DOM; a reused capture shoots only what a new content map adds. In `template-kit.json`: list rows come from the map's slot groups (`rows[]`, `maxFrom: "slot-rows"`); every shown link is listed by `position` (repeated links included) with the icon it draws, and a row icon names the content map slot that holds it as its `field`; links carry an `action` (`contact`, `external-profile`, and the others); fixed text carries a measured `canHide`, CMS language strings name every constant with their value, and copy that is really another item's content moves to `demoOwned`; listing and author pages take the map's items lists and card fields (`checks.itemsListsWithoutCardFields`, which must be 0). A short last row pressed to the left is a template gap only when the content around it is centred; a short row in a left-aligned column, in line with the words beside it, is right. The JA Boxing 1.0.10 contract is re-sealed with author article lists and the footer icon slots, and its approved `template-kit.json` sits beside it.
  **Why / Measured:** on a local stand restored from the 1.0.10 installer the kit reads 54 pages in 10 groups, 80 blocks and 112 images, 0 blocks without a shot, 0 items lists without card fields, 0 open template gaps (32 accepted placeholder links), 4 measurement errors left (three lists with no row set of their size at desktop width, and the Typography page's two h1). The template-kit and content-coverage test files pass one file at a time.
