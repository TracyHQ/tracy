- **The content coverage audit's `--reclassify` reuses the saved module boxes instead of opening every page again** — Quickstart tools · #473 · `fix/ja-voyara-band-button` · 2026-11-08
  **Affects:** `packages/cms/tracy-quickstart-tools/content-coverage` (`lib/verify/module-boxes-saved.mjs`, `lib/label-judge-run.mjs`, `cli.mjs`). Every run now writes `<out>/module-boxes.json` (`module-boxes/1`) with an input fingerprint: site address, database dump sha256, webroot tree hash, audited page list, tool source. A later `--reclassify` or `--report-only` on the same `--out` reuses it when the fingerprint matches; a missing dump or webroot, a missing fingerprint (output from before this change), a mismatch or a saved failed page falls back to the browser with a `[modules]` line on stderr saying why. `--trust-saved-boxes` skips the check and is logged as TRUSTED. A full run always reads the site. The first run after this change still reads the boxes in the browser, since older outputs have no file.
  **Why / Measured:** `findings.json` already held everything classify reads; the label judge's module box pass re-opened all pages at desktop and phone (about 40 minutes on a 352-page template) after every map-only change. `test/content-coverage-module-boxes-saved.test.mjs` is red without the module and green with it.
