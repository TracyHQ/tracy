- **A written text slot counts as printed when the page prints it as an image alt or a title** — Write step bench (card K) · #415 · `fix/site-check-zero-checked` · 2026-11-06
  **Affects:** the printed rule shared by the write step's printed stage and step 11 `written-not-printed` (`lib/printed-in-body.js`): an `<img>` `alt` or any element's `title` in the body now counts, besides the visible text. `data-*` attributes still do not. No change to tracy-host. ADR 0044 decision 11.
  **Why / Measured:** On a bench run six gallery descriptions were blocked as "not printed" while the page printed each as its image's alt (the template prints that slot nowhere else). Covered by an invented-fixture test; not re-run on that site.
- **A slot nested in a kit list's row pair counts on the pages that print the list** — Write step bench (card AY) · #415 · `fix/pictures-never-leave-frame-empty` · 2026-11-06
  **Affects:** the same printed rule (`lib/printed-in-body.js` `slotsOnPages`): a block's slots now include `lists[].rowSlots[]` and the slots nested in them, read by one shared reader (`lib/kit-list-slot-ids.js`) that `write-step/kit-slot-ids.js` (card AA) uses too. No change to tracy-host.
  **Why / Measured:** On a bench run step 11 `written-not-printed` blocked four class intro pictures that the services page and the home class list print, because the kit places them in row pairs and the rule only knew their detail page, where the template keeps the picture in schema data alone.
