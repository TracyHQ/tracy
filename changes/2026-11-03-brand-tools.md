  **`make_icon` (added, #320):** the icon tool draws through the existing picture door `seedImage` (the seeder's `chat` with image output, no new provider client and no environment fallback), injected as `ctx.draw({ prompt, size })` and refusing clearly when the door is unset, disabled or cannot draw. The tool owns the drawing prompt (one subject, no scene, bold shapes, readable at 128 px, no text, plain ground); code removes the ground, turns every pixel into exactly the 1 or 2 given colours and writes a transparent 512 square. When two colours were asked and the model drew one, code puts the icon on a circle or rounded square of the missing colour (3:1 or it fails). Every failure is a tool failure that is not a drawing attempt. Each drawing is checked against the 1 USD cap before it goes out and logged with its cost after (`ctx.spend`); the cost split now counts the drawing. Parity with the lab quantizer and plate code was run locally on invented drawings (same record and identical pixels, one and two colours, JPEG input, plate on a circle and on a rounded square). The end-to-end test now has the gate accept a brand file with a drawn icon and a blind look at 128 px, and still accept the lettermark when every drawing fails.
