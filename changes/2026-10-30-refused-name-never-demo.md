- **A name or line the site refuses as too long for its box never leaves the template's demo words: it is placed within the box, written shorter once, or its card goes whole.** — build maintainers · #189 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** brief builds on Joomla. The site plan now measures an offering's name against the box the template measured for it (`slotCharacterLimit`: the tighter of the contract limit and `fit`), not only the contract limit. A name too long for the box takes a shorter form made only of its own words (`shortOfferingName`, "Seasonal Fruit Tarts" → "Fruit Tarts"); with none, the card is taken off with reason `offering-name-unavailable`. During the contract write, a line the site still refuses with "at most N characters" is written shorter once (`refused-box-rewrite.js`: the text model, checked to stay within the box, without an ellipsis and, for a name, with only the name's own words), and every line of the same write that held the long words takes the short ones. A card whose name is refused again is taken off whole (`name-refused`) before the footer and main menu are written, and the build note names the offering. WordPress and EmDash builds are unchanged. Rebuild the web image before the next brief build.
