- **Road to live and /ops say "Not judged yet" for the plugin write doors of a WordPress release** — Template readiness (spec #452, ticket #454) · `feat/wp-skill-writer-capture` (PR #469) · 2026-11-07
  **Affects:** the people who read Road to live on `/ops/cms/templates`. A WordPress road now ends with a twelfth step, Plugin write doors, in the new state `not-judged` (code `write-doors-not-judged`), taken from the verdict's own write doors check (no second judgement). It renders as a grey "Not judged yet" tag with a hollow bar segment and the registry text "Not judged until the WordPress write step exists...". It is never green, never red, holds nothing (Publish never waits for it) and is left out of the header count, so a live release still reads whole. The step comes last, so no other step changes number. Joomla and EmDash roads are unchanged.
  **Why / Measured:** before, only the command line verdict said the write doors were not judged; the page showed nothing, which read like a pass. Every pinned release's road was dumped before and after the change: the Joomla and EmDash roads are byte for byte the same (with their fixes), and the five WordPress roads gain only the trailing write doors step.
