- **A push whose host job was lost mid-write finishes, or can be undone.** — David · issue #122 · `fix/push-interrupted-resume` · 2026-10-29
  **Affects:** Sync to live. When the host loses an Apply or Undo job (a host restart, a lost container), tracy-web starts the same job again once with the same push id: the host goes on from its write journal, never writes an item twice, and ends with the id map, the push's record and its Sync from live, so the push ends pushed and Undo works as usual. The lease stays the push's in between. An Apply lost twice ends interrupted but keeps Undo, and the host's Undo takes back what the journal lists when the Apply never wrote its answer. New `site_push` columns: `php` (the Owner's PHP confirmation, to start the same job) and `resumed`.
