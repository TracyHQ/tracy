- **Demo farm: every farm change builds a missing farm image before it needs it — `farm-switch.sh`, fold, unfold and refresh no longer fail with "pull access denied" after a deploy that moved `DEMOS_IMAGE`** — fleet operations (agent) · `docs-demo-farm-image-build` · 2026-11-15
  **Affects:** fleet operators and anyone folding a demo on a host whose farm image is not built yet. `farm_config_test` ran a throwaway container of the farm image before `farm_apply` could build it, so on a host without the new tag compose tried to pull `tracy/web-demos` and the change stopped (the farm kept serving). `farm_config_test` now calls `farm_image_ensure` first (a build takes minutes; an image already there changes nothing; when it cannot be had the change fails with that message and touches nothing) (the image is then local, so compose does not pull; `run --pull` is not used because the Compose in tracy-host, v2.29, has no such flag). The runbook and the `farm-switch.sh` header said the updater builds the farm image; it does not — the deploy only warns. See `docs/references/demo-farm.md`.
