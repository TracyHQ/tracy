- **One author replaces the separate copy writers when the site plan is accepted.** — build maintainers · #237 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** Joomla brief builds and operators reading the build record. With an accepted site plan the sibling-list, record-page, offering-description and call-to-action writers get no model call: the plan's author writes those lines, and each of those modules runs as its check alone. A line the author still breaks after its send-back (sibling shape, record page, offering description, call-to-action message) is in `copyLineTrace` as refused with the check it broke, and is taken off or emptied, never left as demo. Offering summaries are checked without a model. Record pages the plan keeps are written as their own step, before every page that lists or summarises them, each record bound to the plan item of the same rank (`record-page` decision `items`), so an offering keeps one name and description on the home page, the list page and its own page. People are glossary items like offerings: a person's name is checked against the glossary on every page, and their role against its description. Without an accepted plan the old writers run as before. WordPress and EmDash are not done. Rebuild the web image before the next brief build.
