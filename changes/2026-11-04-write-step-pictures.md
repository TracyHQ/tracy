- **Write step bench, part 4: pictures reach the site** · Claude, for Akemi · #356 · `feat/write-step-pictures` · 2026-11-04
  **Affects:** whoever runs the write step bench. `node scripts/write-step-bench.mjs run` takes a new optional `--pictures-file <mapping.json>`, the output of `exportPictureMapping`, with its files read relative to it; a run without it works as before. The new `pictures` phase runs after the brand: every listed file through `media.upload`, the shared body background through `template.siteSettings` (`body_bg_img`, plugin 0.24.78 or later, the template and key from the kit's `site.settingSlots`), then the site is read again so the contract call names its current revision. Picture changes join the copy in the one contract call, and a refused slot is written around as before. Pictures join the owner table as owner `picture`, so a dispute stops the run with nothing written. A package with problems, for another contract, or with a file that is missing, over 8 MiB or not its hash stops the run before any call. Frames to hide are reported as skipped for #362 and painted frames as skipped for #367; their preview files are not uploaded. Report lines carry `part`, `ordered`, and `readFrom` for the background. No customer-facing change.
  **Why / Measured:** ADR 0044 decision 4 sends pictures, copy and emptied slots together. Unit tests only, on a fake site door with tiny generated images; the run on dev is still to come.
