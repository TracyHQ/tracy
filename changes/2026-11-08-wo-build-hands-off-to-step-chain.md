- **A Website Opportunities Build press on an enabled template hands the build to the step chain (#479)** — Website Opportunities · #479 · `feat/wo-build-step-chain` · 2026-11-08
  **Affects:** `startBuild()` (`opportunities-build/builds.js`), demo action acceptance (`demo-actions.js`), the demo runner, and the new `lib/step-chain-switch.js`. A template listed in `STEP_CHAIN_TEMPLATES` while `STEP_CHAIN_ENABLED=1` no longer gets a client-send chat action: the press is accepted without a chat mode, so the browser opens no chat and sends no brief. The runner then asks `POST /api/sites` for `workflow: "step-chain/1"` with `researchRevisionId` (the frozen `wo_revision` id) and no `brief`, records the workflow on the build receipt, and ends the action when the site exists (no agent hand-over; the build is marked QA passed and gets its demo clock, so it reaches Outreach and the retention sweep). Templates not listed, a master switch that is off, quality runs, Retry, Build from my business and public demos keep the agent-demo build unchanged. A build already owned by a chat is never switched.
  **Why / Measured:** the chain engine (#483) writes the site itself. Covered by `test/step-chain-switch.test.mjs` and `test/wo-step-chain-handoff.test.mjs` (request shape, no chat message, unchanged agent-demo path). `/api/sites` accepting the new workflow is #483's job.
