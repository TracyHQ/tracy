- **A replaced icon keeps the look of the template icon it replaces: size, line weight and backing are read from that icon's file, and the site check blocks anything else** — Akemi · #380 · `feat/icon-keeps-template-look` · 2026-11-04
  **Affects:** the write step and its bench. A caller passes `templateFiles` (`write-step/site-file.js`; `scripts/write-step-bench.mjs` does), otherwise an icon is drawn as its recipe says, its report line holds no `template`, and the new `icon-look` page group blocks it, naming the picture step. An icon whose template file cannot be read is not drawn and its line fails. The demo baseline now holds `iconFrames`, so a baseline measured before this change has to be measured again or `icon-look` answers unmeasured. The host answers `pictureBoxes` in `pageMeasures`, so the host needs this code too.
  **Why / Measured:** the picture step ran without the template's files, so every icon recipe says `plate: null`, weight `regular` ("no demo icon to measure"), and the drawing filled its box. On JA Boxing the template file is 150x150 with the disc in the file, a thin line, and a drawing 0.56 of the file; the written icon was 100x100, no disc, regular weight and 0.74 to 1 of the file. A neutral backing stays the template's colour, a tint of the template accent takes the brand accent, the drawing stays the recipe's role. A second run reads the same files, draws the same paths and writes nothing.
