- **The site plan's author writes the pages one by one, in the plan's writing order.** — build maintainers · #235 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** Joomla brief builds and operators reading the build record. When the site plan is accepted, the page writer (`plan-joomla-contract.mjs`, option `author`) writes one page per call in the plan's writing order (a summarised page before its summary), each call carrying the rulebook, the page's plan (purpose, lead, facts, items, hidden sections), the glossary, its slots with their limits and the compact text of the pages already written; parts shown on several pages are written last. The site direction call is skipped. A line over its box is sent back like the other shared checks, and glossary names and descriptions are no repeat across pages. A section the plan hid gets no call and its module is unpublished. A line still refused after its send-back is in `copyLineTrace` with the page it was written on, and is taken off or emptied, never left as demo. Per-page time, calls and tokens are on the build record as `pageAuthor`. Without an accepted plan (or one keeping no page) the current writers run unchanged. The sibling, record-page, offering and CTA writers still run after it (#237). Pages are written one after another, so a build takes one call round per page. WordPress and EmDash are not done. Rebuild the web image before the next brief build.
