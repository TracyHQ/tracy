- **The Design system slot gains an accent-only mode: only the accent family changes, every other template colour stays byte for byte** — Claude, for Akemi · #317 · `feat/brand-bench-ds` · 2026-11-03
  **Affects:** `packages/design/tracy-ds-slot` only, and only callers that opt in: `brandProfile(input, contract, base, { accentOnly: true })` followed by `joomlaSlot(profile, base, contract, { accentOnly: true })`. Nothing calls it yet; the brand step's `build_design_system` tool (#314) will. The default output and brand mode are unchanged (pinned by the existing default-unchanged hashes and a new brand-mode hash).
  **Why / Measured:** brand mode on JA Boxing 1.0.10 shifts the template's page text (4.02:1) to read and derives the other side from a palette that includes the accent, so it also moved text, line and ink colours. Accent-only mode ignores any ground, text colour or fonts it is handed, keeps the template's own text, keeps the ink band, derives the other side without the accent, lifts a dark or light accent that has hue until it reads (as brand mode does), and refuses a neutral accent with `neutral-accent`. `test/accent-only-mode.test.mjs` (12 tests) compares a gold, a dark green and a pale yellow accent with the template's own accent on both sides: only accent-family declarations differ and every other `--ds-c-*` colour role is identical.
