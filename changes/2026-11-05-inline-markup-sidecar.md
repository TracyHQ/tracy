- **The JA Boxing 1.0.10 content map is back at its sealed bytes; its inline markup lives in content-coverage.json as a sidecar the template kit reads after the map** · Claude, for Akemi · #370 · `feat/write-step-bench` · 2026-11-05
  **Affects:** whoever resamples or resettles a released Joomla contract, and the template kit tool. #370 had rewritten 64 samples of the released `ja-boxing/j6/1.0.10/content-map.json`, which the Claude Cowork plugin (0.24.79 to 0.24.81) and both `quickstarts.json` pins hold by hash, so the design-templates gate, the pin test and the seeder build were red, and a site bound to that contract would answer "Installed content contract changed". The map is restored (sha256 6ab0ffa2...), and `content-coverage/resample.mjs --sidecar` writes the same 64 markup samples into `content-coverage.json` (`inlineMarkup.samples`) instead. The kit reads the map first and the sidecar second (`template-kit/lib/contract-read.mjs`, every settle command), so the 1.0.10 kit is unchanged: 69 text slots carry `inline`, `inlineMarkupLost` 0. The showcase navigation map follows the sealed map again. ADR 0044 decision 25; the next contract version (1.0.11) carries the markup in its map.
