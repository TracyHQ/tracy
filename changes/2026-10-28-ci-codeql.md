- **CodeQL moves from default setup to `.github/workflows/codeql.yml`: team pull requests into `develop` scan without data, tests and fixtures and can run incrementally; forks and pull requests into `main` still scan everything** — CI maintainer (Claude) · #PR-TBD · `ci-codeql` · 2026-10-28
  **Affects:** every pull request's checks. A repository admin must switch code scanning default setup OFF when this merges, or GitHub rejects the new uploads. `CodeQL (<language>)` runs for team pull requests into `develop`, for pushes to `develop`/`main` and weekly, and reads `.github/codeql/codeql-config.yml` (`paths-ignore` only; adding `queries`/`packs`/`query-filters` there switches incremental analysis off). `CodeQL full (<language>)` runs, with no exclusions, for fork pull requests and every pull request into another base than `develop` (`main`, or a stacked pull request into a feature branch). A pull request into any base gets a scan; retargeting it (`edited` with a base change) starts the scan for the new base, a title or body edit starts nothing. Test and fixture exclusions cover Tracy's own trees only; vendored test folders, which hold Worker entry points, and EmDash's deployed `docs` Worker stay scanned (`scripts/test/ci-public-repo.test.mjs` fails when a pattern hides an entry point named by a `wrangler*` config or a `package.json`). New `Dependency review` job on every pull request. A data, test or fixture folder added under a new name is scanned until its pattern goes into the config.
  **Why / Measured:** 28/10 job logs: a PR JavaScript scan took 22–35 min ("No overlay-base database found in cache"); the `main` overlay base was 9285 MB, over codeql-action's 7500 MB cache cap, because the extractor indexes 894 MB of JSON. The excluded data paths hold about 850 MB of that JSON. codeql-action v4.39.1 builds an overlay base only on the default branch (`src/config-utils.ts` `checkOverlayEnablement`), so the base comes from `main` pushes and the weekly scan. Pull requests into `develop` read it because a default-branch cache is readable from every branch.
