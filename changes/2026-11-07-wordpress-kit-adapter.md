- **The template kit tool builds a kit from a running WordPress block theme site (`wordpress` site adapter); JA Diner WP7 carries its first kit** — Template kit · #453 · `feat/wp-453-wordpress-kit-adapter` · 2026-11-07
  **Affects:** anyone building or reading a template kit. `template-kit/cli.mjs build` now accepts a WordPress contract: page addresses are spelled `/<path>/` (not `/index.php/<path>`), pages are derived from the map's page entities and `inventory.json`, and every page is read as its header and footer template parts plus one block per top-level block of its post content (its sections: hero, menu, subscribe...), read from the database and kept as `wordpress-sections.json` in the work folder; a page not in the map (a single post) keeps its post content as one block. A theme.json palette accent counts as the brand colour even when a status rule reuses it (WordPress only). The WordPress page path rule lives once in `content-coverage/lib/wordpress-page-path.mjs`. Fields WordPress has no equivalent for are left empty and named in `errors` with `kind: "not-on-platform"`. A browser read under `--host-header` now fetches documents from Node with the Host header (Chromium drops it on a continued request), for Joomla too. The pinned release row reads a WordPress manifest's `theme` as its template. New shared test fixture `apps/tracy-web/test/ja-diner-wp7-fixture.mjs` (`dinerWp7()`, and `dinerWp7({ edit })` for a broken copy) for every WordPress verdict test.
  **Why / Measured:** the JA Diner WP7 kit (49 pages, 98 blocks, 244 images, accent #c36349) is read by the readiness verdict: template-kit `todo kit-incomplete` (slot coverage, dead controls, link labels), with flow gap `kit-brand-unreadable` (the header logo has no frame); the Joomla kit tests and verdict tests are unchanged and green.
