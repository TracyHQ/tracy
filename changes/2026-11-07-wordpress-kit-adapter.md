- **The template kit tool builds a kit from a running WordPress block theme site (`wordpress` site adapter); JA Diner WP7 carries its first kit** — Template kit · #453 · `feat/wp-453-wordpress-kit-adapter` · 2026-11-07
  **Affects:** anyone building or reading a template kit. `template-kit/cli.mjs build` now accepts a WordPress contract: page addresses are spelled `/<path>/` (not `/index.php/<path>`), pages are derived from the map's page entities and `inventory.json`, and every page is read as three blocks found by selector (header template part, post content, footer template part) instead of Joomla module wrappers. Fields WordPress has no equivalent for are left empty and named in `errors` with `kind: "not-on-platform"`. A browser read under `--host-header` now fetches documents from Node with the Host header (Chromium drops it on a continued request), for Joomla too. The pinned release row reads a WordPress manifest's `theme` as its template. New shared test fixture `apps/tracy-web/test/ja-diner-wp7-fixture.mjs` (`dinerWp7()`, and `dinerWp7({ edit })` for a broken copy) for every WordPress verdict test.
  **Why / Measured:** the JA Diner WP7 kit (49 pages, 43 blocks, 128 images) is read by the readiness verdict: template-kit `todo kit-incomplete` (slot coverage, dead controls, link labels), with flow gap `kit-brand-colour-from-link`; the Joomla kit tests and verdict tests are unchanged and green.
