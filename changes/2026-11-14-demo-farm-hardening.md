- **Demo farm: fold/unfold lose no write, carry events, and no folded demo can link into another** — fleet operations (agent) · `demo-farm` · 2026-11-14
  **Affects:** fleet operators folding demos. `fold.sh` now stops the demo's own web container right before its database is dumped (the database keeps running) and the demo has no server until the forwarder takes over — measured and printed ("was without a server for N s"); any failure before the switch starts it again with its own settings. `unfold.sh` stops the forwarder before dumping the farm schema the same way; other folded demos keep serving (a farm re-create to change mounts is their only blip). Farm pools also disable `symlink` and `link`, and `fold.sh` refuses (exit 2, by path) a webroot holding a link that leads out of it.
  **Why / Measured:** testing found the dump-before-switch write gap, event loss and the FollowSymLinks cross-demo read. E2E covers each: a routine, a trigger and an event survive fold → unfold, a link to another demo's file stops the fold, farm PHP cannot make a link, and the other demo's probe during a fold.
- **Demo farm hardening: link chains judged by where they end, unfold waits for running PHP, definers stripped only as syntax** — fleet operations (agent) · `demo-farm` · 2026-11-14
  **Affects:** fleet operators. `fold.sh` follows every webroot symlink link by link (`provision/farm_links.py`); a chain ending outside the webroot, a dangling link or a loop refuses the fold. `unfold.sh` takes the demo's vhost out of the farm (Apache graceful) after stopping its forwarder and waits until its pool reports no running request (`pm.status_path`, new in every pool; `provision/farm-pool-status.php`) before the dump; other demos' pools are never reloaded. Definers are dropped by one filter, `lib/strip-definers.sed`, only where mariadb-dump writes them as statement syntax — row text holding the same words is restored byte for byte (fold, unfold, Restore everything, restore.sh).
  **Why / Measured:** normpath let `base/..` chains through; a request inside the farm could write after unfold's dump; the old regex rewrote row content. Each has a test that failed before its fix (unit, real MariaDB, e2e).
- **Demo farm: no demo's PHP can open another demo's PHP-FPM socket** — fleet operations (agent) · `demo-farm` · 2026-11-14
  **Affects:** the farm image (new tag `tracy/web-demos:php8.4-fpm-20261114-r2`, `web/DEMOS_IMAGE`; a host builds it at its next fold or `bash web/build.sh demos`, and the farm moves to it at its next re-render). Apache in the farm runs as `farmhttp` (uid/gid 3301, in the www-data group to read webroots); every pool socket — the demos' and the farm's own — is `farmhttp:farmhttp 0600` in a `root:farmhttp 0750` folder; workers stay www-data and can open none of them. unfold's drain reads a pool's status as root (`php -n`).
