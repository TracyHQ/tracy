- **A brief build's icons and cut-outs reach the page, and the leftover check counts a demo file once per page** — Akemi (Claude) · #189 · `feat/brief-build-own-site` · 2026-10-29
  **Affects:** Joomla brief builds (T3 and T4). Each icon and cut-out decision of the decor plan now carries the brief words that chose it (`asked`), and the picture write sends them as `replace_kept` for every slot the template keeps (Slot fit `replace: "keep"`); the seeder's contract write passes `mapping.replaceKept` through, and joins it to the request id only when sent. The demo-leftover check reports a demo picture file once per page (C01, C04, C05) and a demo logo file once per page (C13), listing every slot that holds it in `slots`.
  **Why / Measured:** on a local brief build on a Joomla T4 template, 24 icons were rendered and uploaded and the site refused every one (`SLOT_PICTURE_KEPT`: item icons are kept pictures), so every page kept the demo's icons. The same build reported 336 demo icons for 8 files on 7 pages and 50 demo logos for 2 files on 10 pages, because one file was counted once per slot that holds it.
