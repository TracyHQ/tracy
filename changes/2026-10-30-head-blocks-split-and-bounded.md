- **Brand colours and leftover rules are written as separate, size-bounded head blocks, and a missing block fails the final check.** — build maintainers · #189 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** Joomla brief builds. The brand colours and the demo-leftover rules no longer share one custom module: each part has its own module (notes `tracy-leftovers`, `tracy-brand-colours`, and numbered parts when needed), so Joomla's 65535-byte module limit (`COM_MODULES_FIELD_CONTENT_TOO_LARGE`) or any other refusal of one part never removes the other. The CSS is packed first (a rule repeated across T4's per-page compiled bundles is kept once, at its last place; neighbouring rules with the same declarations share a selector list), then cut at rule boundaries into as many blocks as needed; no rule is dropped, and a refused block is reported with its size. T3 sites write the colours first and retry with the colours alone when the head-code param is refused. The leftover check gains a head-block check: a served page missing the brand colours block (when the plan takes the logo colours), the leftovers block (when there are leftover rules), or the rule that centres a card row that lost demo cards is a major finding and fails the pass. Rebuild the web image before the next brief build.
