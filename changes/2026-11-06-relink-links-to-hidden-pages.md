- **A link a kept row keeps, to a page the plan hides, goes to a living page of the plan, and what is left reads as plain text (card AM)** — Write step · #TBD · `fix/hide-empty-video-play-buttons` · 2026-11-06
  **Affects:** template kits gain `site.hiddenPageLinks` (`template-kit/cli.mjs hidden-page-links --kit <file> --container '<css>' --why '<where>'`, or `--none`); the JA Boxing 1.0.11 kit names `.teams-item`. On such a kit the contract call writes, in place of an empty the plugin refuses with `SLOT_NOT_HIDEABLE`, the address of a living page (the kept page above the hidden one, else the kept page holding the block), and the line says so; a refused address is a failed line naming both refusals (`write-step/contract-write.js`, `write-step/hidden-page-links-stage.js`). Last of the writes, a rule between `tracy-hidden-links` markers in the head injection block makes the links in those containers that still lead to a hidden page plain text; the look guard allows only that rule (`hidden-page-links` exception). tracy-host's `shownLinks` now carry `clickable`, and a new site check group `hidden-page-links` (block, step 9) fails a shown clickable link to a hidden page; a host image from before this change leaves it unmeasured. The site check now reads `content.list` (a read action). ADR 0044 decision 27 covers this third use.
  **Why / Measured:** card AM: on a bench site with the JA Boxing 1.0.11 kit the coach cards on the home, About and Coaches pages linked name and photo to the dropped trainer profile (`index.php?Itemid=197`, unpublished), and a click answered 404; the plugin refused to empty those slots inside kept rows. In a headless Chromium on an invented page the rule leaves the link unclickable and a link to a living page clickable (`apps/tracy-host/test/demo-qa-reach-measures-browser.test.mjs`).
