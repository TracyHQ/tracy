- **The measuring Chrome's font cache keeps the query of Google's dynamic subset font addresses** — Akemi0x · `feat/ja-boxing-1-0-11-design-system-measurement` · 2026-11-06
  **Affects:** everyone who measures a release for /ops Design system (`flow.mjs`, `preview-check.mjs`, `preview-parity.mjs` through `packages/design/tracy-ds-slot/scripts/cdp.mjs`). Google's css2 sometimes names a face `fonts.gstatic.com/l/font?kit=...&skey=...`; the cache encoded the query into the path, gstatic answered 404, and that face failed on every page that drew it. FONT-1, PREV-1 and PREVIEW-PARITY then failed on whichever systems Google answered that way on that run, a different set each run. Measurements taken before this fix that fail one of those three rules with "a web font did not load" are worth measuring again.
