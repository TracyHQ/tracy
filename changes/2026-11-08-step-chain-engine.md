- **A build of an allow-listed template runs the whole step chain on the server as one build** — Akemi Nguyen · #483 · `feat/step-chain-engine` · 2026-11-08
  **Affects:** `POST /api/sites` takes `workflow: 'step-chain/1'` with `researchRevisionId` (no `brief`) for a template on `STEP_CHAIN_TEMPLATES` while `STEP_CHAIN_ENABLED=1`; anything else builds exactly as before. The brief-build run frame (`sites/brief-build.js`) now picks its engine by that workflow and the template, and an engine may bring its own clocks (`limits`). The chain's model steps are runs of the planner, writer, picture and brand bench queues, so those queues must be running in the server (they are started by `server.js`); a bench holds one run at a time, so concurrent chain builds wait for each other step by step. A failed step never stops the Write step: its best version is used, or stand-in files (`write-step/stand-in-files.js`) let the closing ladder empty every kept slot nothing fills; only an unreadable kit hands the base site over unwritten. Per-step minutes and USD and the ending land in `site_brief.timings.chain`. `STEP_CHAIN_KEEP_FILES=1` keeps a run's step files on disk for inspection.

- **A chain build runs without per-step caps** — Akemi Nguyen · #478 · `feat/chain-no-step-caps` · 2026-11-08
  **Affects:** only builds on the step chain. The frame's 25 minute run cut and apply cut, the planner USD budget (`--no-caps` on the planner bench `run`), the brand cost cap (`--no-caps` on the brand bench `run`, stored as `capUsd: null`) and step 9b's 10 and 12 minute windows (`CHAIN_REPAIR_LIMITS`) no longer apply to it. Steps run until a 2 hour outer deadline, counted from the start of `prepare`; a step still going then is stopped (its best version is used) and the Write step still runs, so the site is handed over as a soft failure. `STEP_CHAIN_HANDOVER_MS` (1 hour) is the frame's backstop for the Write step after the deadline. Bench runs started by hand and every other engine keep their limits. Lost-run detection is unchanged. The writer and picture benches still carry their own `budgetUsd` default.
