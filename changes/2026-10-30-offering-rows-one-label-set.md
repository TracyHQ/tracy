- **Every offering card describes its offering in more than its name, and the cards of one list share one set of info-row labels.** — build maintainers · #189 · `feat/brief-build-own-site` · 2026-10-30
  **Affects:** brief builds. An offering's description or summary never falls back to its name (`offering-description.mjs`). The order is: the business's own words about that offering (its quote when it says more than the name, a line quoted under it, then the title and lines of its own post about it from `content.items`; never a guest review, never a line naming another offering, a different line for each slot of a card); else the copy writer writes one line about that offering from the trade (`acceptsWrittenDescription`: editorial words only, no figure, age, level, year, price or promise the business did not state, never the name again); else the line is taken off. Slots with no owner words are listed in `honesty.nameOnly` for the writer. Copy pins no longer pin the name as a summary (`slot-fill.mjs`). On Joomla the text model writes those lines after the copy writer's pass (`offering-description-writer.js`) and they are kept through the cleanup; any description or summary that still only repeats the name, or stays unwritten, is emptied after the write (`offering-name-only.js`). Fact rows are planned per list, not per card (`planCollectionFactRows`): row n shows the same kind under the same label on every kept card, a kind one card has no value, room or the same label for is shown on none, and a list keeps as many rows as its shortest card. A new final check (`offering-rows-check.js`) reports a line only repeating an offering's name and a list of offering cards with mixed row labels; a kept card with no summary is still reported by the summary check. WordPress and EmDash do not yet run the description writer or the post-write emptying. Rebuild the web image before the next brief build.
