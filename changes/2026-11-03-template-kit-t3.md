- **The template kit reads Joomla T3 templates: blocks by T3 markup and module ids, logo and name from the template style params, brand colours from the template's LESS variables** — Claude, for Akemi · `feat/template-kit-t3` · 2026-11-03
  **Affects:** whoever builds a template kit for a T3 template, and the brand step that reads one. `find-blocks.js` knows `#t3-header`, `#t3-mainbody`, `.t3-off-canvas` and finds an assigned module by an element whose id ends in `-<module id>` (only when exactly one such element exists). The Joomla site adapter has a T3 layer (`lib/site/adapters/joomla-t3.mjs`): logo settings `logotype`, `logoimage`, `logoimage_sm`, `logofooterimage` with what each block layout prints when empty, the style's `sitename` falling back to the CMS name, and the colour variables of `less/variables.less`, so a declared `@brand-primary` stays the primary even where the CSS reuses it for a status rule. `capture-contract.py` gains two flags, both off by default so a recapture stays byte for byte: `--template-style-logos` (T3 logo params become `business.logo` image slots on `templateStyle` entities) and `--skip-trashed-menu-items` (menu items with `published = -2` leave the contract). The next T3 capture (JA Cagox) must pass both. `kitProblem` in `apps/tracy-web/src/brand-step/kit-grounds.js` now refuses a kit with no brand tokens, no sides, no name slots, or a shown logo spot without a frame. `--exclude-path` takes `\,` for a comma inside one pattern, and `readBatch` no longer adds a newline to each file it reads.
  **Why / Measured:** the JA Cagox kit built before this had 4 logo spots with no frame and no empty-state, 0 brand tokens, and primary `#a4321e` instead of the template's `@brand-primary` `#da4e35`. Rebuilt on the same site with this branch: 20 blocks became 296 (4440 slots in blocks, was 46), page groups 125 became 77, all 4 shown logo spots carry a frame (`templateStyle-9.*`) and an empty-state, 231 brand tokens, primary `#da4e35` (`@brand-primary`), zip 51.7 MB (was 55.6 MB). The kit's self-checks now count real gaps (`linksWithoutLabel` 441, `detailPagesOutsideListing` 61, `itemsListsWithoutCardFields` 45, `slotCoverage` 32, `mixedPageGroups` 3) where the old kit's 20 blocks gave 0 everywhere. JA Boxing's committed kit still passes `kitProblem`; the old Cagox kit is now refused.
