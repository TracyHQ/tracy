- **A build from an approved plan writes a site that serves: one item never stops it, and done means the site answers (#575).** -- AI quickstart work for #575 | PR pending | `wip/aiq-575-site` | 2026-11-20
  **Affects:** The build of a site from an approved plan in tracy-web (copy, write order, write plan, the write step) and the plan gate. (1) Skip and continue: a copy field still failing after its rewrite goes back to its no-data rule, a write order entry, alt text or data value the checks refuse is hidden, a Privacy page that fails its check is left out, a page the kit cannot make, a block it does not declare, a page with no copy, a second home page, a container copy over `perPage`, a menu block over its `max`, a packed list gap and a door that refuses one record each leave that item out; every one is listed on the run's record as `skippedItems` (`{code, op, place, reason, detail?, at}`, ids only) and in the log line `draft_write_items_skipped`. Only a plan or order with nothing to write, or no page written, still stops. (2) The write creates categories, articles and contacts before the home menu item, so a first page that links to its category is written; the write plan and the door both keep exactly one default menu item (`default_page_moved`). (3) After the write the site's root and every written page are read as a visitor; a root that does not answer stops the build (`site_not_serving`), another page is listed (`page_not_serving`). (4) A block a kit container holds, placed without its container, gets the container in the build's plan step (`plan-held-containers.mjs`). (5) A template with a `home` page type gets a plan that starts with it: the composer prompt says so and the gate sends a plan that does not back to the model (`home_missing`). (6) The legal and not-found pages of a plan are derived by code (links to pages the plan does not keep are dropped), never a gate failure. The tracy-web image carries it.
  **Why / Measured:** live builds on a test stand stopped on one item (an emphasis, a not-found link, a held block) or ended done on a site with no default menu item (404 at the root); after this change the same plans write to the end and the chat built a serving site.
