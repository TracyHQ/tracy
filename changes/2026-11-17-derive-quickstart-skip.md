- **tracy-host stops retrying the content-contract derive on an imported site that is already bound to a quickstart contract: it marks the site `contract-derived.done` and logs that the site keeps its quickstart contract** — Fleet maintainers · #<PR> · `derive-quickstart-skip` · 2026-11-17
  **Affects:** Rebuild and deploy tracy-host and the fleet scripts. Only a `conflict` that says "bound to a quickstart contract" counts as settled. `joomla-content-derive.php` now reports it as `TRACY_RESULT derived=kept`, and the Joomla and WordPress import roads print it as a plain line instead of "not bound". Every other refusal or error is still a failure and is tried again at the next start. Anything else that reads `derived=` must handle `kept`.
  **Why / Measured:** Dev host, 16/11/2026: `ja-impact-xemaydienhocsinh-com-919d875b` logged "content contract not derived — the script reported derived=failed" on every start. Running the script by hand showed the component refusing with `conflict` "This site is bound to a quickstart contract; derive refuses to replace it". That refusal is by design, because the quickstart contract already serves the Edit picker.
