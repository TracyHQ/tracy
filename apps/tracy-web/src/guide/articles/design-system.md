The look of a whole site (colours, fonts, corner shapes, button style) comes from one design system, picked from the design templates. A new site gets its design when it is created.

**Where:** open the site and press the Design system row on the site's start screen. The tab shows the design system the site wears, applies another one, and can undo it.

**Good to know:**
- Small design changes (one button, one colour, one section) are done by asking Tracy in the chat; they follow the design system the site wears.
- Changing the whole design system of an existing site is done from the Design system tab, not by pasting a style document in the chat.
- Design templates (in the creation workspace) is the gallery of designs a new site can start from.
