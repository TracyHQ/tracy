Tracy's own screens come in English, Vietnamese, German, Italian, French, Dutch, Chinese and Spanish.

**Where:** Settings (gear icon, a dialog, not a tab) → Language.

**Good to know:**
- This changes Tracy's screens, not the language of your website. Adding a language to the website itself is done by asking Tracy in the chat.
- Tracy replies in the language you write in.
