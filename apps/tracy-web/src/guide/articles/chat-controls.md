- While Tracy is working, the send arrow turns into a red Stop square; pressing it stops that work. Pressing Esc twice quickly in the chat box does the same (what you typed stays).
- You can type your next message while Tracy is working: the send button then queues it (it is sent when the current work ends), and Stop stays beside it.
- Lasting wishes: a wish written as a normal chat message with words like "from now on", "always" or "never" is kept for that site and followed in every later chat on it. A request in the current chat that disagrees with it wins. To drop one, say so ("forget that I wanted short answers").
