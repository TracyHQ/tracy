A new site starts as a Draft: only people with the link can open it. Publishing makes it Live.

**Where:** My Sites → the site's "…" menu → Publish. An Owner first chooses "Make it live on Tracy" and presses Continue; an Editor starts there. The Tracy address step shows the site address, its state (Draft / Publishing… / Live), and Publish or Back to draft. Once the site is live, an Owner presses Continue to the "Your domain" step.

**Who:** an Owner or an Editor can publish and go back to draft. A Viewer asks one of them.

**Publish:** press Publish. It takes about a minute. When it is done the state shows Live with the time.

**Back to draft:** hides the site from search engines again and stops it sending email; only people with the link can open it. If the site has its own domain connected, visitors to that domain no longer reach the site until it is published again.

**Good to know:**
- Nothing else can be started while a publish or back-to-draft is running.
- Connecting your own domain needs a Live site and is for the Owner: see "Connect your own domain". Use www.example.com, not example.com.
- An imported site: publishing it does not change your real website on your own hosting. See "Put the changes of an imported site on your real website".
- If publishing fails, the site stays as it was (a draft stays a draft, a live site stays live); the screen says what happened and gives a reference to share with the Tracy team.
