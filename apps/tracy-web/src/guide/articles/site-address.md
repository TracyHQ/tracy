Every site has a Tracy address (for example your-name.tracy.site). An Owner can rename it.

**Where:** the site's Site settings tab → Site URL → Change.

**Steps:** type the new address, press Check availability, then Save. If the name is taken, choose another.

**Good to know:**
- Only an Owner can change the address.
- This is the Tracy address. To use a domain you own (www.yourcompany.com), use Connect domain on the Publish screen instead; see "Connect your own domain".
- Old links to the previous Tracy address stop being the site's address; share the new one.
