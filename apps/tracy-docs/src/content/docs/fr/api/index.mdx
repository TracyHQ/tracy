## Ce que vous pouvez faire en cinq minutes

1. Créez une clé d'API dans **Settings → API keys** du site sur lequel vous détenez un siège.
2. `GET /v1/me` — vérifiez au nom de qui la clé agit, sur quel site, avec quelles portées.
3. `GET /v1/sites/{key}/pages` — listez les pages publiées du site avec les identifiants de leurs contenus.
4. `PATCH /v1/sites/{key}/records/{kind}/{id}` — modifiez un titre, enregistré sous un `apply_id`.
5. `POST /v1/sites/{key}/applies/{apply_id}/revert` — rétablissez-le.

Le [Démarrage rapide](/fr/quickstart/) parcourt exactement ces cinq appels avec `curl`.

## Comment le système est organisé

```text
Bearer trk_…  (you, your agent, a partner's integration)      cookie tracy_sess (a browser on cowork.*)
      |  /v1/*  — Bearer only, no cookie                              |  /api/sites/{key}/apply, /api/me/keys
  api.tracy.ai ── API host ── allowlist ──┐                           |
                 └─ /docs/api/<document>   (this site: docs.tracy.ai) |
                                          ▼                           ▼
                        applyDoor(siteKey, action, params, principal)   ← ONE path: seat · effective permissions ∩ scopes · lease · audit
                                          |
                  Claude Cowork plugin (Joomla, WordPress) · Tracy reader (EmDash)
```

- **`api.tracy.ai`** répond à `/v1/*` et aux trois documents lisibles par machine sous `/docs/api/` (OpenAPI, plugin Claude Cowork, llms.txt). Cette documentation et la référence interactive sont sur **`docs.tracy.ai`**. Rien d'autre : la connexion, l'espace de travail et l'outillage Ops vivent sur le nom d'hôte propre de Tracy et répondent `404 NOT_ON_THIS_HOST` sur les deux.
- **Une seule porte.** Chaque route `/v1` est un simple alias d'une action de la porte Apply — le même chemin que suit l'agent Tracy : qui vous êtes (le propriétaire de la clé), ce que votre siège autorise, le bail d'écriture du site et le journal d'audit.
- **C'est le site qui répond.** Sur Joomla et WordPress, l'appel atteint le plugin Claude Cowork installé sur le site ; sur EmDash, le lecteur propre de Tracy. Ce que le site refuse vous revient sous la forme d'une [erreur](/fr/reference/errors/) documentée.
