## What you can do in five minutes

1. Create an API key in **Settings → API keys** of the site you hold a seat on.
2. `GET /v1/me` — check who the key acts as, on which site, with which scopes.
3. `GET /v1/sites/{key}/pages` — list the site's published pages with their content ids.
4. `PATCH /v1/sites/{key}/records/{kind}/{id}` — change one title, recorded under an `apply_id`.
5. `POST /v1/sites/{key}/applies/{apply_id}/revert` — put it back.

The [Quickstart](/quickstart/) walks through exactly these five calls with `curl`.

## How the system is organised

```text
Bearer trk_…  (you, your agent, a partner's integration)      cookie tracy_sess (a browser on cowork.*)
      |  /v1/*  — Bearer only, no cookie                              |  /api/sites/{key}/apply, /api/me/keys
  api.tracy.ai ── API host ── allowlist ──┐                           |
                 └─ /docs/api/<document>   (this site: docs.tracy.ai) |
                                          ▼                           ▼
                        applyDoor(siteKey, action, params, principal)   ← ONE path: seat · effective permissions ∩ scopes · lease · audit
                                          |
                  Claude Cowork plugin (Joomla, WordPress) · Tracy reader (EmDash)
```

- **`api.tracy.ai`** answers `/v1/*` and the three machine-read documents under `/docs/api/` (OpenAPI, Claude Cowork plugin, llms.txt). This documentation and the interactive reference are on **`docs.tracy.ai`**. Nothing else: sign-in, the workspace and the Ops tooling live on Tracy's own hostname and answer `404 NOT_ON_THIS_HOST` on both.
- **One door.** Every `/v1` route is a thin alias of an action of the Apply door — the same path the Tracy agent takes: who you are (the key's owner), what your seat allows, the site's write lease, and the audit log.
- **The site answers.** On Joomla and WordPress the call reaches the Claude Cowork plugin installed on the site; on EmDash, Tracy's own reader. What the site refuses comes back to you as a documented [error](/reference/errors/).
