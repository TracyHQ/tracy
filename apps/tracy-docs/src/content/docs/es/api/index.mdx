## Qué puedes hacer en cinco minutos

1. Crea una clave de API en **Settings → API keys** del sitio en el que tienes un asiento.
2. `GET /v1/me` — comprueba en nombre de quién actúa la clave, en qué sitio y con qué alcances.
3. `GET /v1/sites/{key}/pages` — lista las páginas publicadas del sitio con los ids de sus contenidos.
4. `PATCH /v1/sites/{key}/records/{kind}/{id}` — cambia un título, anotado bajo un `apply_id`.
5. `POST /v1/sites/{key}/applies/{apply_id}/revert` — vuelve a dejarlo como estaba.

El [Inicio rápido](/es/quickstart/) recorre exactamente estas cinco llamadas con `curl`.

## Cómo está organizado el sistema

```text
Bearer trk_…  (you, your agent, a partner's integration)      cookie tracy_sess (a browser on cowork.*)
      |  /v1/*  — Bearer only, no cookie                              |  /api/sites/{key}/apply, /api/me/keys
  api.tracy.ai ── API host ── allowlist ──┐                           |
                 └─ /docs/api/<document>   (this site: docs.tracy.ai) |
                                          ▼                           ▼
                        applyDoor(siteKey, action, params, principal)   ← ONE path: seat · effective permissions ∩ scopes · lease · audit
                                          |
                  Claude Cowork plugin (Joomla, WordPress) · Tracy reader (EmDash)
```

- **`api.tracy.ai`** responde `/v1/*` y los tres documentos para máquinas bajo `/docs/api/` (OpenAPI, plugin Claude Cowork, llms.txt). Esta documentación y la referencia interactiva están en **`docs.tracy.ai`**. Nada más: el inicio de sesión, el espacio de trabajo y las herramientas de Ops viven en el propio nombre de host de Tracy y en ambos responden `404 NOT_ON_THIS_HOST`.
- **Una sola puerta.** Cada ruta `/v1` es un alias fino de una acción de la puerta Apply — el mismo camino que sigue el agente de Tracy: quién eres (el propietario de la clave), qué permite tu asiento, el arrendamiento de escritura del sitio y el registro de auditoría.
- **El sitio responde.** En Joomla y WordPress la llamada llega al plugin Claude Cowork instalado en el sitio; en EmDash, al lector propio de Tracy. Lo que el sitio rechaza te llega como un [error](/es/reference/errors/) documentado.
