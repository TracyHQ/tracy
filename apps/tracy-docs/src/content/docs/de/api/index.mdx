## Was du in fünf Minuten erledigen kannst

1. Erstelle einen API-Schlüssel unter **Settings → API keys** der Site, auf der du einen Sitz hältst.
2. `GET /v1/me` — prüfe, als wer der Schlüssel handelt, auf welcher Site und mit welchen Scopes.
3. `GET /v1/sites/{key}/pages` — liste die veröffentlichten Seiten der Site mit ihren Inhalts-IDs auf.
4. `PATCH /v1/sites/{key}/records/{kind}/{id}` — ändere einen Titel, protokolliert unter einer `apply_id`.
5. `POST /v1/sites/{key}/applies/{apply_id}/revert` — mach es wieder rückgängig.

Der [Schnellstart](/de/quickstart/) geht genau diese fünf Aufrufe mit `curl` durch.

## Wie das System aufgebaut ist

```text
Bearer trk_…  (you, your agent, a partner's integration)      cookie tracy_sess (a browser on cowork.*)
      |  /v1/*  — Bearer only, no cookie                              |  /api/sites/{key}/apply, /api/me/keys
  api.tracy.ai ── API host ── allowlist ──┐                           |
                 └─ /docs/api/<document>   (this site: docs.tracy.ai) |
                                          ▼                           ▼
                        applyDoor(siteKey, action, params, principal)   ← ONE path: seat · effective permissions ∩ scopes · lease · audit
                                          |
                  Claude Cowork plugin (Joomla, WordPress) · Tracy reader (EmDash)
```

- **`api.tracy.ai`** beantwortet `/v1/*` und die drei maschinenlesbaren Dokumente unter `/docs/api/` (OpenAPI, Claude-Cowork-Plugin, llms.txt). Diese Dokumentation und die interaktive Referenz liegen auf **`docs.tracy.ai`**. Sonst nichts: Anmeldung, Workspace und Ops-Werkzeuge leben auf Tracys eigenem Hostnamen und antworten auf beiden mit `404 NOT_ON_THIS_HOST`.
- **Eine Tür.** Jede `/v1`-Route ist ein dünner Alias für eine Aktion der Apply-Tür — derselbe Weg, den der Tracy-Agent nimmt: wer du bist (der Inhaber des Schlüssels), was dein Sitz erlaubt, die Schreib-Lease der Site und das Audit-Log.
- **Die Site antwortet.** Auf Joomla und WordPress erreicht der Aufruf das auf der Site installierte Claude-Cowork-Plugin; auf EmDash Tracys eigenen Reader. Was die Site ablehnt, kommt als dokumentierter [Fehler](/de/reference/errors/) zu dir zurück.
