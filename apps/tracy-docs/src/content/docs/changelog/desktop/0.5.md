## Highlights
- Getting started on first launch: pick the AI account you already pay for (tools found on this computer come first), choose light or dark, and turn on a notice for when the agent finishes. Reopen it any time from Help. _(Desktop only)_
  <video src="/changelog/0.5/getting-started.mp4" poster="/changelog/0.5/posters/getting-started.jpg" aria-label="Getting started in the desktop app: pick your AI account, choose light or dark, and turn on notifications" autoplay muted loop playsinline controls></video>
- Settings › AI accounts can now connect GitHub Copilot and Grok, next to Claude and ChatGPT. _(Desktop only)_
  ![Settings › AI accounts listing Claude, ChatGPT Codex, GitHub Copilot and Grok](/changelog/0.5/ai-accounts.webp)
- Windows open larger by default, and the app no longer loses track of its settings when it checks for updates. _(Desktop only)_

## Changes
### New
- A Getting started screen on first launch: pick your AI account, with the tools found on this computer listed first; choose light or dark; and get a notice when the agent finishes. Reopen it any time from Help. _(Desktop only)_
- Settings › AI accounts can connect GitHub Copilot and Grok. _(Desktop only)_
### Fixed
- Windows open larger by default. _(Desktop only)_
- The app no longer loses track of its settings when it checks for updates. _(Desktop only)_

## 0.5.1
Released 2026-10-10.
- On Linux, the app opens straight to sign-in instead of first asking you to create a keyring password. _(Desktop only)_
- On Linux, the notification settings button now opens the system panel where one exists and stays out of the way where none does. _(Desktop only)_
- The Getting started screen remembers that you already chose a look. _(Desktop only)_
