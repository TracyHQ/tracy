## Instalación

- **App web:** abre **[cowork.tracy.ai](https://cowork.tracy.ai)**: no hay nada que instalar.
- **App de escritorio (macOS, Windows, Linux):** **[Download desde tracy.ai](https://tracy.ai/download/)**. Muestra las mismas
  páginas que la app web y añade lo que solo una app de escritorio puede hacer, como guardar files en tu ordenador.

Tracy está en beta y es gratis mientras lo esté.

## Desarrollo

Tracy funciona sobre [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) (dsh), un
host de agents de código abierto que sirve una interfaz web hecha de plugins; está incluido como submódulo de git en
`vendor/tracy/deepseek-harness`. Tracy es un proyecto independiente y no está afiliado a DeepSeek.

Los plugins de `packages/` forman la interfaz de Tracy. `apps/tracy-web` se encarga del inicio de sesión, de quién puede trabajar
en cada site y con qué rol, y de la dirección de cada site; `apps/tracy-host` crea los sites, y
cada site se ejecuta en sus propios contenedores Docker, donde también se ejecutan los comandos del agent.
[`SYSTEM.md`](../../SYSTEM.md) describe cómo encaja todo.

| Ruta | Qué contiene |
|---|---|
| `apps/` | `tracy-web` (app web y API), `tracy-host` (crea y ejecuta sites en una máquina), `tracy-docs` (documentación de la API) |
| `packages/` | Los plugins dsh de Tracy, bibliotecas compartidas, la app de escritorio, templates de CMS y herramientas de servidor |
| `vendor/` | Código de terceros sobre el que se construye Tracy: dsh (un submódulo de git) y copias fijadas de otros proyectos |
| `deploy/` | `compose.yml` para todo el sistema en una máquina, ajustes de servidor, `.env.example` |
| `scripts/` | Controles de build (`scripts/check-all.ts`), arranque de dsh, herramientas de release |
| `tests/` | Casos de regresión y suites de extremo a extremo |
| `docs/` | Decisiones de arquitectura (`docs/adr/`) y documentos de referencia |

Inicio rápido (Node 22.19+ o 24+, pnpm, git, Docker):

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

La guía completa —requisitos previos, comandos del día a día y cómo ejecutar todos los servicios con sites reales en
Docker— está en [`docs/running-locally.md`](../running-locally.md). ¿Quieres contribuir? Empieza por
[`CONTRIBUTING.md`](../../CONTRIBUTING.md); todas las personas que participan siguen el [Código de conducta](../../CODE_OF_CONDUCT.md).
