## Entwicklung

Tracy läuft auf [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) (dsh), einem
Open-Source-Agent-Host, der eine aus Plugins aufgebaute Web-Oberfläche bereitstellt; er ist als Git-Submodule in
`vendor/tracy/deepseek-harness` eingebunden. Tracy ist ein unabhängiges Projekt und steht in keiner Verbindung zu DeepSeek.

Die Plugins in `packages/` bilden die Oberfläche von Tracy. `apps/tracy-web` kümmert sich um die Anmeldung, darum, wer an welcher
Site in welcher Rolle arbeiten darf, und um die Adresse jeder Site; `apps/tracy-host` legt Sites an, und
jede Site läuft in eigenen Docker-Containern, in denen auch die Befehle des Agent laufen.
[`SYSTEM.md`](../../SYSTEM.md) beschreibt, wie alles zusammenspielt.

| Pfad | Was dort liegt |
|---|---|
| `apps/` | `tracy-web` (Web-App und API), `tracy-host` (legt Sites auf einem Rechner an und betreibt sie), `tracy-docs` (API-Dokumentation) |
| `packages/` | Die dsh-Plugins von Tracy, gemeinsame Bibliotheken, die Desktop-App, CMS-Templates und Server-Werkzeuge |
| `vendor/` | Fremdcode, auf dem Tracy aufbaut: dsh (ein Git-Submodule) und fest gepinnte Kopien anderer Projekte |
| `deploy/` | `compose.yml` für das ganze System auf einem Rechner, Server-Overrides, `.env.example` |
| `scripts/` | Build-Gates (`scripts/check-all.ts`), dsh-Bootstrap, Release-Werkzeuge |
| `tests/` | Regressionsfälle und End-to-End-Suites |
| `docs/` | Architekturentscheidungen (`docs/adr/`) und Referenzdokumente |

Schnellstart (Node 22.19+ oder 24+, pnpm, git, Docker):

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

Die vollständige Anleitung – Voraussetzungen, alltägliche Befehle und wie Sie alle Dienste mit echten Sites in
Docker betreiben – steht in [`docs/running-locally.md`](../running-locally.md). Sie möchten beitragen? Beginnen Sie mit
[`CONTRIBUTING.md`](../../CONTRIBUTING.md); alle Beteiligten halten sich an den [Verhaltenskodex](../../CODE_OF_CONDUCT.md).
