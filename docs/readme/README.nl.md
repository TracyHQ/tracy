## Ontwikkelen

Tracy draait op [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) (dsh), een
open-source agent-host die een web-interface opgebouwd uit plugins serveert; die zit als git-submodule in
`vendor/tracy/deepseek-harness`. Tracy is een onafhankelijk project en is niet verbonden aan DeepSeek.

De plugins in `packages/` vormen de interface van Tracy. `apps/tracy-web` regelt het inloggen, wie aan welke
site mag werken en in welke rol, en het adres van elke site; `apps/tracy-host` maakt sites aan, en
elke site draait in zijn eigen Docker-containers, waar ook de commando's van de agent draaien.
[`SYSTEM.md`](../../SYSTEM.md) beschrijft hoe alles in elkaar past.

| Pad | Wat er staat |
|---|---|
| `apps/` | `tracy-web` (web-app en API), `tracy-host` (maakt en draait sites op een machine), `tracy-docs` (API-documentatie) |
| `packages/` | De dsh-plugins van Tracy, gedeelde bibliotheken, de desktop-app, CMS-templates en servertools |
| `vendor/` | Code van derden waarop Tracy bouwt: dsh (een git-submodule) en vastgepinde kopieën van andere projecten |
| `deploy/` | `compose.yml` voor het hele systeem op één machine, server-overrides, `.env.example` |
| `scripts/` | Build-controles (`scripts/check-all.ts`), dsh-bootstrap, release-tools |
| `tests/` | Regressiegevallen en end-to-end-suites |
| `docs/` | Architectuurbeslissingen (`docs/adr/`) en referentiedocumenten |

Snel starten (Node 22.19+ of 24+, pnpm, git, Docker):

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

De volledige handleiding — vereisten, dagelijkse commando's en alle services draaien met echte sites in
Docker — staat in [`docs/running-locally.md`](../running-locally.md). Wil je bijdragen? Begin met
[`CONTRIBUTING.md`](../../CONTRIBUTING.md); iedereen die meedoet volgt de [gedragscode](../../CODE_OF_CONDUCT.md).
