## Phát triển

Tracy chạy trên [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) (dsh), một
agent host mã nguồn mở phục vụ giao diện web được ghép từ các plugin; nó nằm trong repo dưới dạng git
submodule tại `vendor/tracy/deepseek-harness`. Tracy là dự án độc lập và không liên kết với DeepSeek.

Các plugin trong `packages/` tạo nên giao diện của Tracy. `apps/tracy-web` lo việc đăng nhập, ai được
làm trên site nào và với vai trò gì, cùng địa chỉ của mọi site; `apps/tracy-host` tạo site, và mỗi site
chạy trong các Docker container riêng, nơi các lệnh của agent cũng chạy.
[`SYSTEM.md`](../../SYSTEM.md) mô tả các phần khớp với nhau thế nào.

| Đường dẫn | Chứa gì |
|---|---|
| `apps/` | `tracy-web` (web app và API), `tracy-host` (tạo và chạy site trên một máy), `tracy-docs` (tài liệu API) |
| `packages/` | Các plugin dsh của Tracy, thư viện dùng chung, app desktop, template CMS và công cụ server |
| `vendor/` | Mã của bên thứ ba mà Tracy dựa vào: dsh (một git submodule) và bản ghim của các dự án khác |
| `deploy/` | `compose.yml` cho toàn hệ thống trên một máy, phần ghi đè cho server, `.env.example` |
| `scripts/` | Cổng kiểm tra khi build (`scripts/check-all.ts`), bootstrap dsh, công cụ release |
| `tests/` | Các ca hồi quy và bộ kiểm thử end-to-end |
| `docs/` | Quyết định kiến trúc (`docs/adr/`) và tài liệu tham khảo |

Bắt đầu nhanh (Node 22.19+ hoặc 24+, pnpm, git, Docker):

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

Hướng dẫn đầy đủ — yêu cầu cài đặt, lệnh dùng hằng ngày và cách chạy mọi dịch vụ với site thật trong
Docker — nằm ở [`docs/running-locally.md`](../running-locally.md). Muốn đóng góp? Bắt đầu với
[`CONTRIBUTING.md`](../../CONTRIBUTING.md); mọi người tham gia đều theo [Quy tắc ứng xử](../../CODE_OF_CONDUCT.md).
