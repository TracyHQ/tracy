## Sviluppo

Tracy gira su [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) (dsh), un
host di agent open source che serve una UI web fatta di plugin; è incluso come submodule git in
`vendor/tracy/deepseek-harness`. Tracy è un progetto indipendente e non è affiliato a DeepSeek.

I plugin in `packages/` compongono l'interfaccia di Tracy. `apps/tracy-web` gestisce l'accesso, chi può
lavorare su quale site e con quale ruolo, e l'indirizzo di ogni site; `apps/tracy-host` crea i site, e
ogni site gira nei propri container Docker, dove vengono eseguiti anche i comandi dell'agent.
[`SYSTEM.md`](../../SYSTEM.md) descrive come si incastra il tutto.

| Percorso | Cosa contiene |
|---|---|
| `apps/` | `tracy-web` (app web e API), `tracy-host` (crea e fa girare i site su una macchina), `tracy-docs` (documentazione API) |
| `packages/` | I plugin dsh di Tracy, le librerie condivise, l'app desktop, i template CMS e gli strumenti server |
| `vendor/` | Codice di terzi su cui Tracy si basa: dsh (un submodule git) e copie fissate di altri progetti |
| `deploy/` | `compose.yml` per l'intero sistema su una macchina, override per i server, `.env.example` |
| `scripts/` | Controlli di build (`scripts/check-all.ts`), bootstrap di dsh, strumenti di release |
| `tests/` | Casi di regressione e suite end-to-end |
| `docs/` | Decisioni architetturali (`docs/adr/`) e documenti di riferimento |

Avvio rapido (Node 22.19+ o 24+, pnpm, git, Docker):

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

La guida completa (prerequisiti, comandi di tutti i giorni e come far girare ogni servizio con site
veri in Docker) è in [`docs/running-locally.md`](../running-locally.md). Vuoi contribuire? Parti da
[`CONTRIBUTING.md`](../../CONTRIBUTING.md); chiunque partecipi segue il [Codice di condotta](../../CODE_OF_CONDUCT.md).
