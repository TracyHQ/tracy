## 开发

Tracy 运行在 [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/)（dsh）之上，
这是一个开源的 agent 宿主，提供由 plugin 组成的 Web 界面；它以 git submodule 的形式包含在
`vendor/tracy/deepseek-harness` 中。Tracy 是独立项目，与 DeepSeek 没有关联。

`packages/` 中的 plugin 构成了 Tracy 的界面。`apps/tracy-web` 负责登录、谁可以在哪个 site 上
以什么角色工作，以及每个 site 的地址；`apps/tracy-host` 负责创建 site，每个 site 都运行在自己的
Docker 容器中，agent 的命令也在其中执行。
[`SYSTEM.md`](../../SYSTEM.md) 说明了这一切如何组合在一起。

| 路径 | 内容 |
|---|---|
| `apps/` | `tracy-web`（Web 应用与 API）、`tracy-host`（在一台机器上创建并运行 site）、`tracy-docs`（API 文档） |
| `packages/` | Tracy 的 dsh plugin、共享库、桌面应用、CMS template 和服务器工具 |
| `vendor/` | Tracy 所依赖的第三方代码：dsh（git submodule）以及其他项目的固定版本副本 |
| `deploy/` | 在一台机器上运行整个系统的 `compose.yml`、服务器覆盖配置、`.env.example` |
| `scripts/` | 构建检查（`scripts/check-all.ts`）、dsh 引导、release 工具 |
| `tests/` | 回归用例和端到端测试套件 |
| `docs/` | 架构决策（`docs/adr/`）和参考文档 |

快速开始（Node 22.19+ 或 24+、pnpm、git、Docker）：

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

完整指南——前置条件、日常命令，以及在 Docker 中用真实 site 运行所有服务——请见
[`docs/running-locally.md`](../running-locally.md)。想要贡献？请从
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) 开始；所有参与者都须遵守[行为准则](../../CODE_OF_CONDUCT.md)。
