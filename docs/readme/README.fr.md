## Installation

- **Application web :** ouvrez **[cowork.tracy.ai](https://cowork.tracy.ai)** — rien à installer.
- **Application de bureau (macOS, Windows, Linux) :** **[Download depuis tracy.ai](https://tracy.ai/download/)**. Elle affiche les mêmes
  pages que l'application web et ajoute ce que seule une application de bureau peut faire, comme enregistrer des files sur votre ordinateur.

Tracy est en bêta et gratuit tant qu'il l'est.

## Développement

Tracy repose sur [DeepSeek Harness](https://deepseek-harness.github.io/deepseek-harness/) (dsh), un
hôte d'agents open source qui sert une interface web composée de plugins ; il est inclus comme sous-module git dans
`vendor/tracy/deepseek-harness`. Tracy est un projet indépendant et n'est pas affilié à DeepSeek.

Les plugins de `packages/` composent l'interface de Tracy. `apps/tracy-web` gère la connexion, qui peut travailler
sur quel site et avec quel rôle, ainsi que l'adresse de chaque site ; `apps/tracy-host` crée les sites, et
chaque site tourne dans ses propres conteneurs Docker, où s'exécutent aussi les commandes de l'agent.
[`SYSTEM.md`](../../SYSTEM.md) décrit comment l'ensemble s'articule.

| Chemin | Ce qu'on y trouve |
|---|---|
| `apps/` | `tracy-web` (application web et API), `tracy-host` (crée et fait tourner les sites sur une machine), `tracy-docs` (documentation de l'API) |
| `packages/` | Les plugins dsh de Tracy, les bibliothèques partagées, l'application de bureau, les templates CMS et l'outillage serveur |
| `vendor/` | Le code tiers sur lequel Tracy s'appuie : dsh (un sous-module git) et des copies figées d'autres projets |
| `deploy/` | `compose.yml` pour tout le système sur une seule machine, les surcharges serveur, `.env.example` |
| `scripts/` | Contrôles de build (`scripts/check-all.ts`), amorçage de dsh, outillage de release |
| `tests/` | Cas de régression et suites de bout en bout |
| `docs/` | Décisions d'architecture (`docs/adr/`) et documents de référence |

Démarrage rapide (Node 22.19+ ou 24+, pnpm, git, Docker) :

```bash
git clone --recurse-submodules https://github.com/TracyHQ/tracy.git && cd tracy
pnpm dsh:build && pnpm install --frozen-lockfile
pnpm build:check
```

Le guide complet — prérequis, commandes du quotidien et lancement de tous les services avec de vrais sites dans
Docker — se trouve dans [`docs/running-locally.md`](../running-locally.md). Envie de contribuer ? Commencez par
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) ; toute personne qui participe suit le [Code de conduite](../../CODE_OF_CONDUCT.md).
