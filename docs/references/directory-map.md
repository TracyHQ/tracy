# Directory map — every package in `packages/`, every tree in `vendor/`

Moved verbatim from §1 of [`CLAUDE.md`](../../CLAUDE.md) on 29/09/2026 so that CLAUDE.md keeps only the high-level map and the boundary rules. Only relative paths and § references were changed for the new location.

## `packages/`

**`packages/`** — TRACY CODE, the only thing that leaves this machine (repo → image → customer). Plugin test: has `cordis.patch.yml` → dsh plugin; otherwise library/app — never guess by folder name.
- LIBRARIES (not plugins):

  - `wo/website-opportunities` = `website-opportunities` (the open Website Opportunities layer: `src/` = the server's doors, executor, place store and `wo_*` schema, moved from `apps/tracy-web/src/opportunities/` 24/10/2026; `domain/` = discovery, crawler, connectors, media, brand, brief — plain ESM, every fetch injected. tracy-web imports it by name through the root `workspace:*` link, and its image copies it whole to `node_modules/website-opportunities`; the future public package, [ADR 0036](../adr/0036-website-opportunities-independent-public-repo.md); a `vendor/` subtree until 24/10/2026).

## `vendor/`

**`vendor/`** — others' code: `deepseek-harness` = submodule; every other folder = subtree pinned to one commit (list: ADR 0006 §2). See RULE #5. **MUST READ** `docs/adr/0006-plugins-as-pinned-subtrees.md` before adding a plugin — no dependency may point at live GitHub; find existing plugins at dshmarket.com · dshfind.com.
- `tracy-wordpress-theme` (group `wordpress/`) — WordPress 7 site-building SKILL: spec-pack → generated theme → wp-cli seed → parity/editability gates → theme zip → fleet quickstart. NOT a slash command in TCH (only `.agents/skills/` is mirrored): read `vendor/wordpress/tracy-wordpress-theme/skills/tracy-wordpress-theme/SKILL.md` in place. Pinned commit: top of its `IMPORT-NOTE.md` (`0c6362e` on 06/10, untagged — trace it by commit, not version number; the note explains why).
- `refero` (group `tracy/`) — a snapshot of Refero Styles data, imported under a separate agreement Lee confirmed on 08/10/2026. Keeps source UUIDs, original results, Compact/Extended exports and screenshots; catalogue/hashes/completeness in `snapshot.json` and `source/`. An internal library for later integration, NOT a plugin/workspace member and NOT in the image (`.dockerignore`). The source is a website, not yet an upstream subtree: read `vendor/tracy/refero/IMPORT-NOTE.md`.
- `emdash-theme-tracy-editorial`, `emdash-theme-tracy-coral` (renamed from `-apple`/`-airbnb` on 26/10/2026 for brand-neutral names) — Tracy's EmDash templates wearing od-design-system systems `apple` and `airbnb`. TWO INDEPENDENT TREES (Lee, 10/09): one customer site = one template = one skin, no picker. They differ in 4 files plus 3 present on one side only (`diff -rq`, recounted 29/09: `IMPORT-NOTE.md`, `package.json`, `src/design-system.json`, `src/layouts/Base.astro`; `styles/systems/<id>.css` and its dark twin); the rest are identical — markup/layout edits go into BOTH. Derived from `emdash-theme-bravada`, version `0.10.0-tracy.2` (EmDash 1.0.1 since 29/09), GPL-3.0-or-later.
- `dsh-passwords` — ⚠ Tracy EDITS this tree (RULE #5 reversed, scanned by `check-language`): fork of slywalker2006/dsh-passwords, the gateway on 8080 (sign-in door, seat door, every site's fence). Base upstream v2.6.6 (`2.6.6-tracy.N`); since 05/10/2026 shaped by [ADR 0027](../adr/0027-dsh-passwords-upstream-base-tracy-policy-layer.md): upstream core pinned byte-for-byte, Tracy's policy in `src/tracy/` behind a closed list of hooks, ledger `vendor/tracy/dsh-passwords/TRACY-FORK.md`, line `tasks/todo-dsh-passwords-2-7-7.md`.
- `emdash-theme-bravada` — ⚠ Tracy EDITS this tree (like `dsh-passwords`; RULE #5 reversed): fork of vhscom/emdash-theme-bravada @ v0.10.0, root of Tracy's EmDash templates. GPL-3.0-or-later: derivatives are GPL too, and mixing in `@tracy/cms-sections` is a LICENSING decision to settle first. `vendor/emdash/emdash-theme-bravada/IMPORT-NOTE.md`.
- `tracy-emdash-skill` — EmDash template-building SKILL; Tracy's own code, but its home is `JoomlArt-Products/tracy-emdash-template` (private), pinned at the commit named at the top of its `IMPORT-NOTE.md` (`af69c10` on 25/09, the merge of upstream PR #6; last tag `v1.5.2`). No `-tracy.N` patch, not a workspace member, NOT in the image (a `.dockerignore` line keeps it out of the build context); the fleet builds by cloning the tag on the droplet, not from this tree. `vendor/emdash/emdash/IMPORT-NOTE.md`.
- 📒 **`deepseek-harness` fork ledger: [`vendor/tracy/deepseek-harness/TRACY-FORK.md`](../../vendor/tracy/deepseek-harness/TRACY-FORK.md) (since 29/09/2026).** It lists what Tracy carries on top of upstream (re-carry on every upstream merge), what Tracy relies on in upstream without a patch (slots, registration ids, `data-*` hooks, hashed class names by TCH package — walk it after a merge), and the bump procedure. Read it before bumping the fork or merging an upstream release; add a row for every new fork patch.
- 🔒 **`git submodule update` BEFORE COMMITTING; never `git add -A` before it.** Checkout doesn't move submodules, so your `deepseek-harness` stays old while `main` moves on, and `add -A` commits that OLD pointer, rolling the whole repo back (happened at `606c6d82`: pointer dragged back to `f2af2af7d6`). No gate catches it, and `git status` shows it as one ordinary-looking line (the `pre-push` hook now blocks it on shared branches, §6).
