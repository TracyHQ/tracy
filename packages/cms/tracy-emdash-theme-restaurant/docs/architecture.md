# Architecture

Template `tracy-restaurant` (label "JA Restaurant", `template.config.json`): a port of the Joomla/T3 template
JA Restaurant j6 1.0.6 to EmDash 1.1.0 on Astro 7.2.8, Tailwind 4.3.3, shadcn 4.21.0 (`package.json`).
Read `../AGENTS.md` first. This is an EmDash/Astro application, not a Joomla template.

## Runtime and storage

- `astro.config.mjs`: `output: 'server'`, adapter `@astrojs/node` (`standalone`); start with `node ./dist/server/entry.mjs`.
- CMS state is persistent and outside source: SQLite at `$SITE_DATA_DIR/data.db` (default `./data`) and media in
  `./uploads` (served at `/_emdash/api/media/file/<key>`, `src/lib/media.ts`). Both are gitignored; `astro.config.mjs` creates them.
- One locale (`en`); the default locale is never prefixed (`src/lib/i18n.ts`).
- `src/middleware.ts`: redirects a trailing slash to the bare path (301), optional `TRACY_FRAME_ANCESTORS` framing header, keeps stamped answers out of shared caches.

## Routing

- `src/pages/[...path].astro` is the only router. In order: `/` renders `Home.astro`; `/blog`, a category (`/<category>` for the four in `BLOG_SIDEBAR`), `/explore/j-pages/featured-articles` and `/explore/j-pages/tagged-items` render `BlogList.astro`; `/gallery` and `/gallery/<album>` render `Gallery.astro`; `/explore/j-pages/smart-search` renders `Search.astro`; every other path in `src/lib/page-routes.json` (the model's page routes) renders `Page.astro` with that entry's slug; `/<category>/<slug>` (and `/pages/<slug>`) renders `Post.astro`; anything else renders `NotFound.astro` with status 404.
- `src/pages/404.astro` answers the literal `/404` with the same view.
- Post detail: `Post.astro` loads the `posts` entry by slug and returns 404 unless the entry's first `category` term equals the URL's first segment.
- `src/lib/page-routes.json` (12 pages, 4 lists, generated by `ingest/build-route-table.mjs` from the model's routes) is read by the router; the pages the source had and the template does not port are not in it and answer 404 with the chrome. A catch-all is not proof of every URL: the route audit evidence is the proof.
- Seed `redirects` (4: `/submit-an-article`, `/template-settings`, `/site-settings`, `/homepage` -> `/`) are applied by EmDash, not by the router.

## Source layout

- `src/layouts/Base.astro`: head (SEO via `emdash/page`, canonical, hreflang alternates, fonts, design-system slot, theme script), skip link, `Header`, slot, `Subscribe`, the `after-subscribe` slot (the home gallery strip), `Footer`. Only place that imports `src/styles/global.css`.
- `src/views/`: `Home`, `Post`, `BlogList`, `Gallery`, `Page`, `Search`, `NotFound`; page composition (which entries fill which band) is code here.
- `src/components/site/`: `Header`, `Footer`, `BrandLogo`, `PageOwner`, `Prose*`, `FormWords`; `Subscribe`, `Pager`, `PostCard`; `sections/`: `Masthead`, `Sidebar`, `Slideshow`, `MenuTabs`, `Dishes`, `FeaturesCollage`, `FeaturesIntro`, `Stats`, `Team`, `Timeline`, `HappyHours`, `Reservation`, `Contact`, `Categories`, `GalleryStrip`; `ui/`: shadcn primitives.
- `src/lib/`: `chrome.ts` (chrome entry + the `primary` menu), `content.ts` (`section`, `sections` by slug), `posts.ts` (posts + category, `postPath`), `html.ts` (allow-list), `media.ts`, `i18n.ts`/`ui.ts`/`ui-words.ts` (words and dates), `stamps.ts` (preview provenance), `ds-slot.ts`, `brand.ts`, `hreflang*.ts`.
- `src/styles/tokens.css`, `global.css`: see `design-system.md`.
- `tools/`, `tests/`, `docs/`, `AGENTS.md`, `seed/`, `ingest/`, `contract/` ship with the package (`inventory/` stays in the repository); `tools/content-api` is injected only when `TRACY_CONTENT_API_SCALARS=1` (Dockerfile sets it).

## Plugins (registered in `astro.config.mjs`)

`@emdash-cms/plugin-audit-log`, `@emdash-cms/plugin-forms` (honeypot), `emdash-smtp`, and the local `tracy-hreflang` plugin. Table and usage: `../seed/plugin-matrix.md`.

## Source vs generated vs persistent

| Kind | What |
|---|---|
| Source (edit) | `src/**`, `astro.config.mjs`, `template.config.json`, `compile.config.json`, `ingest/**`, `tools/**`, docs |
| Generated, committed | `seed/*.json`, `seed/media/**`, `src/lib/page-routes.json`, `inventory/routes.json`, `inventory/assets.json` (by `ingest/`); `docs/generated/*` (by `tools/generate-docs.mjs`) |
| Generated, ignored | `dist/`, `.astro/`, `node_modules/` |
| Persistent site state | `data/` (SQLite, receipts, tokens), `uploads/`, `data/ds-slot.css` (design system slot) |

The seed is a baseline; an installed site's edits live in `data/` and are not overwritten by source changes.

## Rebuilding the seed

`SRC_WORK=<work dir> ingest/rebuild-seed.sh` (work dir holds `spec/`, `j6/`, `webroot/`, `source-snapshot/`). Steps in order are listed in `content-model.md`. It needs the Joomla source stand's dump; it is not part of installing the template.
