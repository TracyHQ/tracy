# Architecture — tracy-nova (P0)

- **Stack** (pins from the sibling Fresco, `package.json`): emdash 1.1.0 on Astro 7.4.12 (SSR, `@astrojs/node`), Tailwind CSS 4.3.3, shadcn/ui primitives, React 19 islands where needed, SQLite (`better-sqlite3`) under `./data`, media under `./uploads`. Standalone pnpm project (own lockfile, `pnpm-workspace.yaml` marker).
- **Kit-owned files** (`new-template.sh`, held byte for byte by `check-emdash-kit-sync`): `tools/`, `contract/`, `ingest/` (kit part), `src/lib/{brand,media,display-locale,stamps,form-embed-words,font-subsets}`, `BrandLogo.astro`, `tests/` of the kit. Never edited per template.
- **Template-owned** (P2–P5): `seed/` (site-model → compiled seed, field-map, personalize, questions, slot limits), `src/layouts/Base.astro`, `src/views/*` (one per page family), `src/components/blocks/*` (one per T4/ACM block: hero, features intro, text slider, clients, teams, pricing, accordion, social, CTA, news band, counters), `src/components/site/*` (header, off-canvas, megamenu, footer, theme toggle), `src/styles/global.css` (Tailwind + `--ds-c-*` colour roles with the template value as fallback).
- **Content model** (from the 12 site-model types): `pages`, `posts` (articles and projects), `hero`, `features_intro`, `text_slider`, `cta`, `clients`, `teams`, `pricing`, `accordion`, `social`, `modules`; menus `mainmenu`, `services`, `jpages`, `jcontent`, `users`, `hidden`; taxonomy of tags. P2 settles the collections against the Home sections (one entry per block, editable in the admin).
- **Runtime identity**: dev site on port 4360 (`data/` and `uploads/` gitignored); Docker stand for release checks.
- **Source stand**: Joomla 6.1.1 + MariaDB in Docker on `127.0.0.1:18082` (`source/REBUILD.md`); snapshot mirror served by `python3 -I -m http.server` on `127.0.0.1:18218` for `render-source.mjs`.
