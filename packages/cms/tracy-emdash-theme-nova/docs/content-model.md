# Content ownership

Read ../AGENTS.md and generated/inventory.md (the generated schema and counts describe the seed only; read current ids and edits from the installed CMS).

| Where | Collection (admin label) | What it holds |
| --- | --- | --- |
| Header, footer, 404, search and pager words, every label the template prints | `chrome` (one entry, slug `chrome`) | brand, header phone and e-mail, footer text, copyright, labels, `logo_dark` |
| Page records (title, banner, summary, visibility, header menu) | `pages` | 14 entries: home, about, career, services, project, contact, blog, illustration and the six service pages; field `view` and `path` |
| Posts and projects | `posts` + taxonomy `category` | title, excerpt, body, cover, author, tags, dates; `kind` tells a blog post from a project; the `project_*` fields hold client, budget, services, date and link of a project |
| Home, About, Services, Career bands | `hero`, `features_intro`, `text_slider`, `cta`, `clients`, `teams`, `pricing`, `accordion`, `social` | entries named in `src/lib/page-layout.json` (for example `home-hero`, `home-intro-1`, `products-cards`, `about-intro`, `services-cards`, `career-positions`, `faq`, `home-cta`) |
| Contact page | `contact` (one entry, `contact-layout`) | words, address, phone, e-mail, `form_id` (bound by `template.config.json` forms.bindings) |

Menus (Admin > Menus): `primary`, `services` (side menu of the service pages), `footer-company`, `footer-work`. Taxonomy `category`: uncategorised, blog, project, branding, ui-ux-design, illustration, services; the project lists use branding, ui-ux-design and illustration.

A new page is a `pages` entry, a row in `src/lib/page-routes.json` (the router reads it), the bands it carries in `src/lib/page-layout.json`, and a menu item. A new band is an entry of a section collection plus its row in `page-layout.json` (both files are generated by `ingest/shape-model.mjs`: change them there so a rebuild keeps them). Keep business copy in the CMS fields, never in HTML blobs.
