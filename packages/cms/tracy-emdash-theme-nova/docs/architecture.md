# Architecture

Read ../AGENTS.md. generated/inventory.md lists discovered route source files and declared dependencies, not all effective URLs or active plugins.

- **Runtime.** Astro 7 in SSR mode with the Node standalone adapter (`astro.config.mjs`); EmDash 1.1.0 stores content in SQLite (`data/data.db`, from `SITE_DATA_DIR`) and media in `uploads/`. Plugins registered in `astro.config.mjs`: audit log, forms, SMTP, the local hreflang plugin (`src/lib/hreflang-plugin.ts`); Tracy's Content API reader (`tools/content-api`) only when `TRACY_CONTENT_API_SCALARS=1` (the Dockerfile sets it). `src/live.config.ts` declares the EmDash live collection; `src/middleware.ts` removes a trailing slash (301), optionally sets `frame-ancestors` from `TRACY_FRAME_ANCESTORS`, and keeps stamped answers out of shared caches.
- **Routing.** One catch-all, `src/pages/[...path].astro`, serves every public address: `/`, `/blog` and `/blog/<slug>`, `/search`, `/contact`, the pages listed in `src/lib/page-routes.json` (`about`, `career`, `services`, `project`, and the six service pages), the project lists `/project/<branding|ui-ux-design|illustration>` and a project at `/project/<category>/<slug>`. Anything else renders `src/views/NotFound.astro` with status 404; `src/pages/404.astro` serves `/404`. A page whose `pages` record is unpublished, and what hangs under it, answers 404 (`src/lib/link-gate.ts`).
- **Layout and views.** `src/layouts/Base.astro` is the only place `src/styles/global.css` is imported (never the admin). Views in `src/views/`: Home, Page, Service, Contact, BlogList, Post, Search, NotFound. Which section entry fills which band of a page, its block style and its spacing are in `src/lib/page-layout.json` (generated by `ingest/shape-model.mjs`); `src/components/blocks/Sections.astro` prints them in that order, one block component per section collection (`src/components/blocks/`, with the features-intro styles in `blocks/features/`).
- **Components.** `src/components/site/` holds header, off-canvas menu, footer, breadcrumbs, search box, post cards, pager, share row, theme toggle, the contact form and the prose renderers. `src/components/ui/` is empty.
- **Chrome.** `src/lib/chrome.ts` loads the `chrome` entry, the menus `primary`, `footer-company`, `footer-work` and `services`, and the `social` entries once per request.
- **State.** Source (this folder) vs build output (`dist/`, `.astro/`) vs persistent CMS state (`data/`, `uploads/`): only the first is in the package. Seed (`seed/`) is a baseline applied by `tools/bootstrap-site.sh` / `tools/seed-apply.mjs`; it never overwrites what an editor changed.
- This is an EmDash/Astro application, not a Joomla PHP template. Route audit evidence: `tools/audit.mjs` and `tools/qa.mjs --browser` write it into an acceptance run; the route contract is `seed/site-model.json` `routes`.
