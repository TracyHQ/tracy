# Tracy SaaS (`@tracy/emdash-theme-saas`)

**Tracy SaaS** (template id `tracy-saas`) is Tracy's EmDash template for a SaaS/product website,
ported from the JA Kinetic Joomla 6 quickstart. Demo content is **Helix**, a fictional observability
product, in English: three home variants (Terminal, Blueprint, Signal — the same page in three colour
directions), features, integrations, changelog, FAQ, pricing, about, team, contact, landing, a blog with
240 posts (categories, tags, authors, archive, search), legal pages and a 404.

Every word, image, menu and number is editable in the EmDash admin. Pages are compositions of section
entries whose order is itself content (`docs/content-model.md`); the look is the template's.
Identity, locales, form bindings and the SEO audit policy live in `template.config.json`.

Built with **EmDash 0.37** on **Astro 7** (SSR, Node adapter) and **Tailwind CSS 4**.
Build record and decisions: `tasks/emdash-ja-kinetic/` in the TCH repository (not shipped).

Licence: GPL-2.0-or-later (`LICENSE`), released by JoomlArt on 26/10/2026 together with the quickstart
design, content and images it is ported from (`docs/content-rules.md`, `PROVENANCE.md`).

## Requirements

Node ≥ 22.16 (24.11.1 used), pnpm 11. Everything else is pinned in `package.json` + `pnpm-lock.yaml`.

## Install and run (development)

```bash
pnpm install --frozen-lockfile
pnpm exec astro dev --port 4370 --host 127.0.0.1      # daemon: `pnpm exec astro dev status|logs|stop`
tools/bootstrap-site.sh http://127.0.0.1:4370 ./data  # setup, admin + agent token, schema/content/media/forms
```

Bootstrap is safe to rerun and never forces: content equal to the seed is adopted, anything an editor
changed is kept and reported (exit 3 = entries need a decision).

## Install and run (built)

```bash
pnpm install --frozen-lockfile
pnpm build
HOST=127.0.0.1 PORT=4361 node dist/server/entry.mjs &
tools/bootstrap-site.sh http://127.0.0.1:4361 ./data
```

`tools/clean-install.sh <empty-dir> <port>` does the same from a fresh copy and refuses unsafe destinations.

## Rebuilding the seed from the source

The seed is generated, never edited by hand. With the quickstart running locally (Docker, see
`tasks/emdash-ja-kinetic/STATUS.md` in TCH) and the two sibling-skill scripts available:

```bash
node <tracy-wordpress-theme>/scripts/ingest/joomla-dump.mjs --out <j6> --compose <compose-dir>
node ingest/joomla-extra.mjs --compose <compose-dir> --out <j6>/extra.json
node <tracy-wordpress-theme>/scripts/ingest/from-joomla.mjs <j6> --out <spec> --site-url <joomla-origin>
node ingest/normalize-joomla-model.mjs --spec <spec> --j6 <j6> --out seed/site-model.json
node contract/validate.mjs seed/site-model.json
node tools/compile-seed.mjs seed/site-model.json seed --config seed/compile.config.json
node ingest/finish-seed.mjs --seed seed --model seed/site-model.json --images <quickstart>/images
node tools/validate-seed.mjs seed/seed.json
```
