# Architecture

Read ../AGENTS.md. generated/inventory.md lists discovered route source files and declared dependencies, not all effective URLs or active plugins.

- **Runtime.** Astro 7 in SSR mode with the Node standalone adapter (`astro.config.mjs`); EmDash 1.1.0 stores content in SQLite (`data/data.db`, from `SITE_DATA_DIR`) and media in `uploads/`. Plugins registered in `astro.config.mjs`: audit log, forms, SMTP, the local hreflang plugin (`src/lib/hreflang-plugin.ts`); Tracy's Content API reader (`tools/content-api`) only when `TRACY_CONTENT_API_SCALARS=1` (the Dockerfile sets it).
- **Routing.** One catch-all, `src/pages/[...path].astro`, serves every public address: `/`, `/about`, `/donations` and `/donations/<slug>`, `/events` and `/events/<slug>`, `/blog` (`?page=N`) and `/blog/<slug>`, `/help-faqs`, `/contact`, `/search`. Anything else renders `src/views/NotFound.astro` with status 404 (with the site header and footer). `src/pages/404.astro` serves `/404`. A page whose `pages` record is unpublished (and its children) answers 404 (`src/lib/link-gate.ts`).
- **Layout and views.** `src/layouts/Base.astro` is the only place `src/styles/global.css` is imported (never the admin). One view per page family in `src/views/`; page composition (which section entry fills which band, in which block style) is code, with the vertical rhythm per section kept in `src/lib/page-layout.json` (generated by `ingest/shape-model.mjs`).
- **Blocks.** `src/components/blocks/` holds one component per source block (hero, helpline card, features intro / cards / stats / fund panel / connected band, donation card and strip, events, blog masonry, section head); `src/components/site/` holds header, footer, masthead, breadcrumbs, pagination, the sidebar, the article body and the prose renderers.
- **State.** Source (this folder) vs build output (`dist/`, `.astro/`) vs persistent CMS state (`data/`, `uploads/`): only the first is in the package. Seed (`seed/`) is a baseline applied by `tools/bootstrap-site.sh` / `tools/seed-apply.mjs`; it never overwrites what an editor changed.
- This is an EmDash/Astro application, not a Joomla PHP template. Route audit evidence: `tools/audit.mjs` and `tools/qa.mjs --browser` write it into the acceptance run.
