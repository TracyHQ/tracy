# JA Impact: instructions for agents

Read this before changing anything. It describes the **installed WordPress site and its theme**,
not the Tracy skill (`tracy-wordpress-theme`) that produced them.

Theme: **WP Impact**, slug `wp-ja-impact`, text domain `wp-ja-impact`, version in `style.css`
(`Version:` is stamped at build; 1.0.0 when these documents were written). Requires WordPress 7.0
and PHP 8.1; built on WordPress 7.1.2 / PHP 8.3. The site it carries is "JA Impact", a charity
and non-profit site, ported from the JoomlArt Joomla 6 quickstart `quickstart/ja-impact/j6`
(template `ja_impact` 1.2.2) so that it renders the same pages; the WordPress quickstart is
released under the tag `quickstart/ja-impact/wp7`. Dependency: **Contact Form 7**
(`contact-form-7`) draws the contact form.

## Rules

1. This is a WordPress **block theme**. Templates, parts and patterns are files under
   `wp-content/themes/wp-ja-impact/`; the site's words are rows in the database. Read
   docs/architecture.md before touching either.
2. Identify the target before any command: `wp option get siteurl`, `wp theme list --status=active`
   (expect `wp-ja-impact`), the webroot path and the process owner. Never assume a localhost stand.
3. Content is edited **through WordPress** (the editor, `wp post update`, or the REST API) as block
   markup. Do not edit the SQL dump, and do not paste a whole page into one `core/html`. Read
   docs/content-model.md for where each kind of text lives.
4. Every file of the theme is **generated by a build** (`@tracy/wordpress-theme`, target
   `wp-ja-impact`) and replaced whole by the next theme update (`theme.json`, `styles/`,
   `patterns/`, `templates/`, `parts/`, `assets/`, `inc/`): a hand edit is lost silently. Overrides
   go in the Site Editor (they become database rows) or a child theme.
5. The header and footer are **database rows** (`wp_template_part` `header` and `footer`, written by
   the seeder). They shadow `parts/*.html`: editing the files changes nothing on this site. The
   `contact` part (the navy contact band above the footer) is a file until someone saves it in the
   Site Editor.
6. A section inserted into a page is a **copy**: editing the page changes that page only. The seed
   created **no synced patterns** (`wp_block`). A new section goes in from the editor, Patterns >
   JA Impact (`wp-ja-impact/acm-*`); locate its blocks by `metadata.name`.
7. Some behaviour hangs on **slugs and options**, not on blocks: the 404 text on option
   `wp_ja_impact_404_page`, the redirect rules in `wp_ja_impact_redirects`, the search page on the
   draft page `smart-search`, the account templates on the page template slugs `page-login`,
   `page-register`, `page-account`, `page-password`. Read docs/content-model.md before renaming,
   moving or publishing a page.
8. Dark mode: three states kept in the `tracy_theme` cookie and applied as `data-theme` on `<html>`;
   no attribute = auto, the operating system decides (docs/design-system.md).
9. Do not fabricate business facts, legal text, people, prices or images. Everything on the site is
   demonstration data until the owner replaces it; a gap is recorded, not filled. Read
   docs/content-rules.md.
10. Back up before a structural change (`wp db export`, `wp-content/uploads`); the quickstart is the
    site **as built**, not a rollback target. The theme gets **no automatic update offer**; install
    a newer zip by hand. Read docs/checks-and-recovery.md.
11. Report separately: file changes, database changes, checks run, what could not be verified.
