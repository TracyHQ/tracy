# JA Fresco: instructions for agents

Read this before changing anything. It describes the **installed WordPress site and its theme**,
not the Tracy skill (`tracy-wordpress-theme`) that produced them.

Theme: **WP Fresco**, slug `wp-ja-fresco`, text domain `wp-ja-fresco`, version in `style.css`
(`Version:` is stamped at build; 1.0.0 when these documents were written). Requires WordPress 7.0
and PHP 8.1; built on WordPress 7.1.3. The site is "fresco", a restaurant site ported from the
JoomlArt Joomla 6 quickstart `quickstart/ja-fresco/j6` (template `ja_fresco` on the T4 framework)
so that it renders the same pages. The contact page uses Contact Form 7 when it is active.

## Rules

1. This is a WordPress **block theme**. Templates, parts and patterns are files under
   `wp-content/themes/wp-ja-fresco/`; the site's words are rows in the database. Read
   docs/architecture.md before touching either.
2. Identify the target before any command: `wp option get siteurl`, `wp theme list --status=active`
   (expect `wp-ja-fresco`), the webroot path and the process owner. Never assume a localhost stand.
3. Content is edited **through WordPress** (the editor, `wp post update`, or the REST API) as block
   markup. Do not edit a SQL dump, and do not paste a whole page into one `core/html`. Read
   docs/content-model.md for where each kind of text lives.
4. Every file of the theme is **generated by a build** (`@tracy/wordpress-theme`, target
   `wp-ja-fresco`) and replaced whole by the next theme update: a hand edit is lost silently.
   Overrides go in the Site Editor (database rows) or a child theme.
5. The header and footer are theme parts. Once edited in the Site Editor they become
   `wp_template_part` rows that shadow `parts/*.html`; the seeded site already has such rows for
   `header` and `footer`. Check for them before editing a file.
6. A section inserted into a page is a **copy**: editing the page changes that page only. A new
   section goes in from the editor (Patterns > WP Fresco, `wp-ja-fresco/*`); locate its blocks by
   `metadata.name`, never by position.
7. Some behaviour hangs on **slugs, templates and options**, not on blocks: the page slug
   (`jf-route-<slug>` body class, the home layout), the page template (account forms, author grid),
   the 404 text on option `wp_ja_fresco_404_page`, the search page on the draft `smart-search`.
   Read docs/content-model.md before renaming, moving or publishing a page.
8. One look: the source has a single dark design, so light and dark are the same palette and no
   toggle is shown (D-01, open; docs/design-system.md).
9. Do not fabricate business facts, legal text, people, prices or images. Everything on the site is
   demonstration data until the owner replaces it; a gap is recorded, not filled. Read
   docs/content-rules.md, which also lists the decisions still open (D-01, D-02, D-05, D-09, D-10,
   D-19).
10. Back up before a structural change (`wp db export`, `wp-content/uploads`). The theme gets **no
    automatic update offer**; install a newer zip by hand. Read docs/checks-and-recovery.md.
11. Report separately: file changes, database changes, checks run, what could not be verified.
