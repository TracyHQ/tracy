# Kept for later

Controls this version holds fixed on purpose. Each one can be opened in a later update of this
template, and of other templates where it fits. Read this before adding a setting for any of them.

## The 3D scene

The site owner can replace the object (see [object-template.md](object-template.md)). Everything
else in the scene is decided by the template:

- Turning the object's motion on or off.
- Choosing a preset camera angle.
- Camera angle and the camera path as the page scrolls.
- Light position, strength and shadow type.
- The object's motion and its rhythm with the scroll.
- Layout of each block and where text sits around the object.
- The rule for when the page falls back to the still image.

## The object

- Separately moving parts, such as a lid that lifts open. The object template asks for one piece.

## The shop

- Ordering, table booking and a cart on the page.
