# Provenance — what this template is made of

Tracy Coffee (`tracy-coffee`, `@tracy/emdash-theme-coffee`) starts as a copy of Tracy Base
(`tracy-base`, `@tracy/emdash-theme-base` 0.5.6): the folder `packages/cms/tracy-emdash-theme-base`
of `TracyHQ/tracy` at commit `9800b339f2fceb78e6a4a5bc69124a3cb274e550`, copied whole into this
repository's root on 2026-10-30 (`git archive`, not a subtree or submodule), under the same
GPL-3.0-or-later. Changed on copy: the identity (id, label, package name, version 0.1.0, theme
storage key) and the two imports of `tools/release.mjs` from outside the package, which now read
the `tracy` checkout named by `TRACY_CHECKOUT`. The table below is Tracy Base's own record.
